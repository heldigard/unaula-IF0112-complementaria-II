🌐 Ejercicio 10: WiFi - Conexión a Red

⏱️ 35 min | 📶 Solo ESP32 | 🟠 Medio

🎯 Objetivo

Conectar el ESP32 a una red WiFi y mostrar la dirección IP asignada.

⚠️ Nota Importante: Este código funciona en hardware real. En Wokwi, la conexión está "simulada" - el ESP32 mostrará que se "conectó" pero no hay red real. Con hardware real, debes cambiar SSID y contraseña.

📋 Código

#include <WiFi.h>

// Credenciales WiFi (CAMBIAR en hardware real)
const char* ssid = "TU_RED_WIFI";
const char* password = "TU_CONTRASENA";

void setup() {
  Serial.begin(115200);

  Serial.println("=== Conexión WiFi ===");

  // Iniciar conexión
  WiFi.begin(ssid, password);

  Serial.print("Conectando a ");
  Serial.println(ssid);

  // Esperar conexión
  int intentos = 0;
  while (WiFi.status() != WL_CONNECTED && intentos < 20) {
    delay(500);
    Serial.print(".");
    intentos++;
  }

  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\n✅ Conectado!");
    Serial.print("Dirección IP: ");
    Serial.println(WiFi.localIP());
    Serial.print("Fuerza de señal: ");
    Serial.print(WiFi.RSSI());
    Serial.println(" dBm");
  } else {
    Serial.println("\n❌ No se pudo conectar");
    Serial.println("Verifica SSID y contraseña");
  }
}

void loop() {
  // Verificar estado de conexión
  if (WiFi.status() == WL_CONNECTED) {
    // Mantener conexión viva
    delay(5000);
  } else {
    Serial.println("Conexión perdida. Reconectando...");
    WiFi.reconnect();
  }
}

🔧 Para Usar en Hardware Real

  1. Cambia TU_RED_WIFI por el nombre de tu red
  2. Cambia TU_CONTRASENA por tu contraseña WiFi
  3. Sube el código a tu ESP32 físico
  4. Abre el Monitor Serial a 115200 baudios
  5. Verás tu dirección IP (ej: 192.168.1.100)

📊 Salida Esperada

Conexión WiFi ===
Conectando a TU_RED_WIFI
.....
✅ Conectado!
Dirección IP: 192.168.1.100
Fuerza de señal: -45 dBm

🔍 Cómo Probar en Wokwi

  1. Copia el código en Wokwi
  2. Ejecuta la simulación
  3. Abre el Monitor Serial
  4. Espera a que muestre "Conectando..."
  5. Observa la dirección IP asignada (Wokwi simula la conexión)
  6. El código de reconexión automática funciona si se pierde la conexión

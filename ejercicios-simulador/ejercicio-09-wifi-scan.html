📶 Ejercicio 9: WiFi - Escanear Redes

⏱️ 30 min | 📶 Solo ESP32 | 🟠 Medio

🎯 Objetivo

Aprender a usar el WiFi del ESP32 para escanear y mostrar las redes WiFi disponibles.

⚠️ Nota Importante: En Wokwi, el WiFi está simulado. El escáner mostrará redes "falsas" generadas por el simulador, pero el código es el mismo que usarías con hardware real.

📋 Código

#include <WiFi.h>

void setup() {
  Serial.begin(115200);

  // Configurar WiFi en modo estación
  WiFi.mode(WIFI_STA);
  WiFi.disconnect();

  Serial.println("=== Escaneo de Redes WiFi ===");
  Serial.println("Escaneando...");

  // Iniciar escaneo
  int n = WiFi.scanNetworks();

  if (n == 0) {
    Serial.println("No se encontraron redes");
  } else {
    Serial.print(n);
    Serial.println(" redes encontradas:");

    for (int i = 0; i < n; ++i) {
      // Mostrar información de cada red
      Serial.print(i + 1);
      Serial.print(": ");
      Serial.print(WiFi.SSID(i));
      Serial.print(" (");
      Serial.print(WiFi.RSSI(i));
      Serial.print("dBm)");
      Serial.println(")");

      // Pequeño delay entre redes
      delay(10);
    }
  }

  Serial.println("\nEscaneo completado!");
}

void loop() {
  // No hacemos nada en el loop
}

🔍 Funciones WiFi

  • WiFi.mode(WIFI_STA): Configura como Estación (cliente WiFi)
  • WiFi.scanNetworks(): Escanea redes disponibles
  • WiFi.SSID(i): Nombre de la red i
  • WiFi.RSSI(i): Potencia de señal en dBm

📸 Instrucciones de Entrega

  1. Ejecuta el escaneo en el simulador
  2. Observa las redes "falsas" que muestra Wokwi
  3. Toma pantallazo del Monitor Serial
  4. Sube a Canvas

⚡ Ejercicio 15: Edge Computing

⏱️ 30 min | 📦 ESP32 + LDR + LED | 🟠 Medio

🎯 Objetivo

Implementar procesamiento local (Edge Computing) para filtrar y validar datos de un sensor antes de "enviarlos a la nube", demostrando la diferencia entre procesamiento en el edge vs cloud.

💡 Contexto: Edge Computing procesa datos localmente en el dispositivo, reduciendo latencia, uso de ancho de banda y mejorando la privacidad. Es clave en IoT industrial y aplicaciones en tiempo real.

📚 Edge vs Cloud Computing

AspectoEdge ComputingCloud Computing
Latencia⚡ Muy baja (ms)🐢 Alta (segundos)
Ancho de banda✅ Bajo uso❌ Alto uso
Privacidad✅ Datos locales⚠️ Datos en servidores

📋 Diagrama de Conexión

Componentes:

  • 1 x ESP32 DevKit V1
  • 1 x LDR (fotorresistencia)
  • 1 x Resistencia 10kΩ (para LDR)
  • 1 x LED + Resistencia 220Ω

Conexiones:

LDR:
  Un lado → 3.3V
  Otro lado → GPIO34 + Resistencia 10kΩ
  Resistencia 10kΩ → GND

LED:
  GPIO18 → 220Ω → Ánodo LED → Cátodo LED → GND

📋 Código: Procesamiento Edge

// Ejercicio 15: Edge Computing - Procesamiento Local
// Filtra, valida y solo "envía" datos significativos

const int ldrPin = 34;
const int ledPin = 18;

// Variables para promedio móvil
const int MUESTRAS = 10;
int lecturas[MUESTRAS];
int indice = 0;
int total = 0;

// Variables para detección de cambios
int luxAnterior = 0;
const int UMBRAL_CAMBIO = 5;  // Solo envía si cambia más de 5%

// Estadísticas Edge
int lecturasProcesadas = 0;
int datosEnviados = 0;
unsigned long ultimoEnvio = 0;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);

  // Inicializar buffer de promedio móvil
  for (int i = 0; i < MUESTRAS; i++) {
    lecturas[i] = 0;
  }

  Serial.println("=== Edge Computing Demo ===");
  Serial.println("Procesando datos localmente...");
  Serial.println("----------------------------------------");
}

void loop() {
  // 1. LEER SENSOR (simulado cada 100ms)
  int lecturaRaw = analogRead(ldrPin);

  // 2. FILTRO: Promedio móvil (reduce ruido)
  total -= lecturas[indice];
  lecturas[indice] = lecturaRaw;
  total += lecturaRaw;
  indice = (indice + 1) % MUESTRAS;

  int promedio = total / MUESTRAS;
  int lux = map(promedio, 0, 4095, 0, 100);  // Convertir a %

  lecturasProcesadas++;

  // 3. VALIDACIÓN: Descartar lecturas inválidas
  if (lux < 0 || lux > 100) {
    Serial.println("⚠️ Lectura inválida descartada");
    return;
  }

  // 4. DETECCIÓN DE CAMBIO SIGNIFICATIVO
  int cambio = abs(lux - luxAnterior);
  bool cambioSignificativo = (cambio >= UMBRAL_CAMBIO);

  // 5. DECISIÓN EDGE: ¿Enviar o no?
  bool debeEnviar = false;
  String razon = "";

  if (cambioSignificativo) {
    debeEnviar = true;
    razon = "Cambio significativo";
  }
  else if (millis() - ultimoEnvio > 10000) {  // Cada 10 seg mínimo
    debeEnviar = true;
    razon = "Actualización periódica";
  }

  // 6. ACCIÓN LOCAL (siempre, sin importar envío)
  if (lux < 30) {
    digitalWrite(ledPin, HIGH);  // Poca luz → LED on
  } else {
    digitalWrite(ledPin, LOW);
  }

  // 7. ENVIAR A "NUBE" (solo si necesario)
  if (debeEnviar) {
    datosEnviados++;
    ultimoEnvio = millis();

    Serial.println("📤 ENVIANDO A NUBE:");
    Serial.print("   Lux: ");
    Serial.print(lux);
    Serial.print("% | Razón: ");
    Serial.println(razon);
    Serial.println("---");

    luxAnterior = lux;
  }

  // Mostrar estadísticas cada 50 lecturas
  if (lecturasProcesadas % 50 == 0) {
    float eficiencia = (1.0 - (float)datosEnviados / lecturasProcesadas) * 100;
    Serial.println("📊 ESTADÍSTICAS EDGE:");
    Serial.print("   Lecturas procesadas: ");
    Serial.println(lecturasProcesadas);
    Serial.print("   Datos enviados: ");
    Serial.println(datosEnviados);
    Serial.print("   Ahorro de ancho de banda: ");
    Serial.print(eficiencia, 1);
    Serial.println("%");
    Serial.println("========================================");
  }

  delay(100);
}

🔍 Qué Demostramos

Técnica EdgeBeneficio
Promedio móvilReduce ruido del sensor
Validación de datosDescarta lecturas imposibles
Detección de cambiosSolo envía datos significativos

Ahorro de ancho de bandaReduce tráfico a la nube
💡 Observa: El LED responde INMEDIATAMENTE a los cambios de luz (acción local), pero los datos solo se "envían" cuando hay un cambio significativo o periódicamente. Esto es Edge Computing en acción.

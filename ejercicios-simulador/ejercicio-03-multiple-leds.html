🔴🟢🟡 Ejercicio 3: Múltiples LEDs

⏱️ 25 min | 📦 3 LEDs | 🟡 Fácil

🎯 Objetivo

Controlar múltiples LEDs simultáneamente usando arrays y bucles for.

🔌 Diagrama de Conexión

Componentes Necesarios

  • 3x LEDs (rojo, verde, amarillo o colores diferentes)
  • 3x Resistencias de 220Ω (una por LED)
  • ESP32

Conexiones

LED Ánodo (+) → Pin ESP32 Cátodo (-) → Resistencia → GND
LED 1 GPIO 18 Resistencia 220Ω → GND
LED 2 GPIO 19 Resistencia 220Ω → GND
LED 3 GPIO 21 Resistencia 220Ω → GND

Diagrama del Circuito

💡 Notas Importantes:
  • Cada LED necesita su propia resistencia de 220Ω
  • NUNCA conectes múltiples LEDs en paralelo con una sola resistencia
  • El ánodo (pata larga) SIEMPRE va hacia el pin del ESP32
  • El cátodo (pata corta) SIEMPRE va hacia GND (tierra)
  • Los GPIO 18, 19 y 21 son pines de salida digital del ESP32
  • Puedes usar cualquier color de LED: rojo, verde, amarillo, azul, etc.
🔧 Tip de Práctica:

Usa LEDs de colores diferentes (rojo, verde, amarillo) para visualizar mejor las secuencias del programa. Esto hace más fácil identificar qué LED está encendido en cada momento.

📋 Código

// Ejercicio 3: Múltiples LEDs con Arrays
const int numLeds = 3;
const int leds[numLeds] = {18, 19, 21};  // Pines para los 3 LEDs

void setup() {
  Serial.begin(115200);
  Serial.println("=== Ejercicio 3: Múltiples LEDs ===");

  // Configurar todos los LEDs como salida usando un bucle
  for (int i = 0; i < numLeds; i++) {
    pinMode(leds[i], OUTPUT);
  }

  Serial.println("LEDs configurados. Iniciando secuencia...");
}

void loop() {
  // Secuencia 1: Encender uno por uno
  Serial.println("Secuencia: Encendiendo uno por uno");
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(leds[i], HIGH);
    Serial.print("LED ");
    Serial.print(i + 1);
    Serial.println(" encendido");
    delay(500);
  }

  delay(500);

  // Secuencia 2: Apagar uno por uno (en reversa)
  Serial.println("Secuencia: Apagando en reversa");
  for (int i = numLeds - 1; i >= 0; i--) {
    digitalWrite(leds[i], LOW);
    Serial.print("LED ");
    Serial.print(i + 1);
    Serial.println(" apagado");
    delay(500);
  }

  Serial.println("---");
  delay(1000);
}

🔍 Conceptos Clave

Arrays en Arduino

const int leds[3] = {18, 19, 21};
  • Un array es una colección de valores del mismo tipo
  • Los índices comienzan en 0: leds[0] = 18, leds[1] = 19, etc.

Bucles For

for (int i = 0; i < 3; i++) {
  // Este código se repite 3 veces
  // i vale 0, luego 1, luego 2
}

🌅 Ejercicio 5: PWM - Dimmer LED

⏱️ 25 min | 📦 1 LED | 🟠 Medio

🎯 Objetivo

Aprender a usar PWM (Pulse Width Modulation) para controlar el brillo de un LED progresivamente, creando un efecto de "fade in/fade out".

💡 Concepto: PWM simula voltajes intermedios encendiendo y apagando el LED muy rápido. El ojo humano percibe esto como variación de brillo.

📋 Diagrama de Conexión

Componentes Necesarios:

  • 1 x LED (cualquier color)
  • 1 x Resistencia 220Ω o 330Ω
  • Cables de conexión

Pasos de Conexión:

1 Identificar el LED:
  • La patilla larga es el ánodo (+)
  • La patilla corta o lado plano es el cátodo (−)
2 Conectar el circuito:
  • Conecta el ánodo (+) del LED a un extremo del resistor de 220Ω
  • El otro extremo del resistor va al pin D18 del ESP32
  • El cátodo (−) del LED va a GND
⚠️ Pines PWM del ESP32: No todos los pines soportan PWM. Los pines PWM incluyen: D2, D4, D5, D12-D19, D21-D23, D25-D27, D32-D33. El pin D18 usado en este ejercicio es PWM.

📋 Código

// Ejercicio 5: PWM - Dimmer de LED
const int ledPin = 18;  // Debe ser un pin que soporte PWM

int brillo = 0;
int incremento = 5;

void setup() {
  Serial.begin(115200);
  Serial.println("=== Ejercicio 5: PWM Dimmer ===");
}

void loop() {
  analogWrite(ledPin, brillo);

  Serial.print("Brillo: ");
  Serial.print(brillo);
  Serial.print(" / 255 = ");
  Serial.print((brillo * 100) / 255);
  Serial.println("%");

  brillo += incremento;

  // Cambiar dirección en los límites
  if (brillo <= 0 || brillo >= 255) {
    incremento = -incremento;
  }

  delay(30);  // Pequeño delay para suavizar la animación
}

🔍 ¿Qué es PWM?

PWM (Pulse Width Modulation) modula el ancho del pulso para simular voltajes intermedios:

  • analogWrite(pin, 0) = 0% de voltaje (LED apagado)
  • analogWrite(pin, 127) = 50% de voltaje (LED al medio brillo)
  • analogWrite(pin, 255) = 100% de voltaje (LED al máximo brillo)

📸 Instrucciones de Entrega

  1. Ejecuta la simulación y observa el LED cambiar de brillo suavemente
  2. Verifica el Monitor Serial mostrando el porcentaje de brillo
  3. Toma un pantallazo del LED en diferentes niveles de brillo
  4. Sube a Canvas

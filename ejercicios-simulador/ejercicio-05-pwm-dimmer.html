🌅 Ejercicio 5: PWM - Dimmer LED

⏱️ 25 min | 📦 1 LED | 🟠 Medio

🎯 Objetivo

Aprender a usar PWM (Pulse Width Modulation) para controlar el brillo de un LED progresivamente.

📋 Diagrama de Conexión

Componentes Necesarios:

  • 1 x LED (cualquier color)
  • 1 x Resistencia 220Ω o 330Ω
  • Cables de conexión

Conexiones:

  • Ánodo (+) del LED → Pin D18 del ESP32 (a través del resistor)
  • Cátodo (-) del LED → Pin GND del ESP32
⚠️ Importante: El pin D18 del ESP32 soporta PWM (modulación por ancho de pulso). Si usas otro pin, verifica que soporte PWM o el LED solo se encenderá/apagará sin variación de brillo.

Diagrama ASCII:

    ESP32 D18 ───[220Ω]──[LED+]──[LED-]── GND
         │
         └── PWM controla el brillo

💡 Nota: Este circuito es igual al del Ejercicio 1. La diferencia está en el código, que usa PWM en lugar de digitalWrite() para variar el brillo.

📋 Código

// Ejercicio 5: PWM - Dimmer de LED
const int ledPin = 18;  // Debe ser un pin que soporte PWM

int brillo = 0;
int incremento = 5;

void setup() {
  Serial.begin(115200);
  Serial.println("=== Ejercicio 5: PWM Dimmer ===");
}

void loop() {
  analogWrite(ledPin, brillo);

  Serial.print("Brillo: ");
  Serial.print(brillo);
  Serial.print(" / 255 = ");
  Serial.print((brillo * 100) / 255);
  Serial.println("%");

  brillo += incremento;

  // Cambiar dirección en los límites
  if (brillo <= 0 || brillo >= 255) {
    incremento = -incremento;
  }

  delay(30);  // Pequeño delay para suavizar la animación
}

🔍 ¿Qué es PWM?

PWM (Pulse Width Modulation) modula el ancho del pulso para simular voltajes intermedios:

  • analogWrite(pin, 0) = 0% de voltaje (LED apagado)
  • analogWrite(pin, 127) = 50% de voltaje (LED al medio brillo)
  • analogWrite(pin, 255) = 100% de voltaje (LED al máximo brillo)

📨 Ejercicio 12: MQTT - Protocolo de Mensajería

⏱️ 50 min | 📶 ESP32 + MQTT Library | 🟠 Medio-Alto

🎯 Objetivo

Entender y utilizar MQTT (Message Queuing Telemetry Transport), el protocolo más utilizado en IoT. Publicar y suscribirse a mensajes en tiempo real.

💡 Concepto: MQTT es un protocolo ligero, simple y eficiente diseñado específicamente para conexiones no confiables en entornos IoT.

📋 Conceptos Clave de MQTT

Concepto Descripción
Broker Servidor central que recibe y distribuye mensajes
Topic "Ruta" o categoría a la que se envían/reciben mensajes
Publish Enviar mensajes a un topic específico
Subscribe Recibir mensajes de un topic específico

🛠️ Paso 1: Instalar MQTT Library

  1. En Arduino IDE, ve a Sketch → Include Library → Manage Libraries
  2. Busca "PubSubClient"
  3. Instala la versión más reciente
  4. Reinicia Arduino IDE

📋 Código - Publicador (ESP32)

#include <WiFi.h>
#include <PubSubClient.h>

// Credenciales WiFi
const char* ssid = "TU_RED_WIFI";
const char* password = "TU_CONTRASENA";

// Configuración MQTT
const char* mqttServer = "broker.emqx.io";  // Broker público MQTT
const int mqttPort = 1883;
const char* mqttTopic = "laboratorio/temperatura";

// Cliente MQTT
WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  delay(1000);

  // Conectar WiFi
  Serial.println("Conectando WiFi...");
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\n✅ WiFi Conectado!");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());

  // Configurar cliente MQTT
  client.setServer(mqttServer, mqttPort);
}

void loop() {
  // Reconectar MQTT si se perdió conexión
  if (!client.connected()) {
    connectMQTT();
  }

  // Publicar mensaje cada 5 segundos
  client.publish(mqttTopic, "Hola desde ESP32 MQTT!");

  Serial.println("✅ Mensaje publicado: " + String(mqttTopic));

  delay(5000);
}

void connectMQTT() {
  // Intentar conectar
  while (!client.connected()) {
    Serial.print("Conectando a MQTT...");
    String clientId = "ESP32_" + String(random(10000, 99999));

    if (client.connect(clientId.c_str())) {
      Serial.println(" ✅ Conectado!");
      Serial.print("Suscrito al topic: ");
      Serial.println(mqttTopic);
    } else {
      Serial.print(" ❌ Falló, rc=");
      Serial.print(client.state());
      Serial.println(" - Reintentando en 5 segundos...");
      delay(5000);
    }
  }
}

📋 Código - Suscriptor (ESP32 - Opcional)

Este código permite recibir mensajes MQTT:

#include <WiFi.h>
#include <PubSubClient.h>

const char* ssid = "TU_RED_WIFI";
const char* password = "TU_CONTRASENA";

const char* mqttServer = "broker.emqx.io";
const int mqttPort = 1883;
const char* mqttTopic = "laboratorio/temperatura";

WiFiClient espClient;
PubSubClient client(espClient);

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\n✅ WiFi Conectado!");

  client.setServer(mqttServer, mqttPort);
  client.setCallback(callback);

  Serial.println("Suscrito a: " + String(mqttTopic));
}

void loop() {
  if (!client.connected()) {
    connectMQTT();
  }

  client.loop();
}

void connectMQTT() {
  while (!client.connected()) {
    Serial.print("Conectando MQTT...");
    String clientId = "ESP32_" + String(random(10000, 99999));

    if (client.connect(clientId.c_str())) {
      Serial.println(" ✅ Conectado!");
      client.subscribe(mqttTopic);
    } else {
      Serial.println(" ❌ Falló, reintentando en 5s");
      delay(5000);
    }
  }
}

// Callback cuando llega mensaje
void callback(char* topic, byte* payload, unsigned int length) {
  Serial.print("📨 Mensaje recibido [");
  Serial.print(topic);
  Serial.print("]: ");
  Serial.write(payload, length);
  Serial.println();
}

🔧 Cómo Probar MQTT

  1. Sube el código de Publicador al ESP32
  2. Abre el Monitor Serial (115200 baudios)
  3. Verás mensajes publicados cada 5 segundos
  4. Para probar suscripción, usa el código de Suscriptor o una herramienta como:
    • MQTT Explorer: https://mqtt-explorer.com/ (gratis)
    • MQTT.fx: https://mqttfx.jensd.de/ (gratis)
    • HiveMQ Web Client: https://www.hivemq.com/demos/websocket-client/

🌐 Broker MQTT Público - broker.emqx.io

  • Broker: broker.emqx.io
  • Port: 1883 (sin SSL)
  • Websocket: wss://broker.emqx.io:8084/mqtt
  • TLS: 8883
⚠️ Nota: broker.emqx.io es un broker público para pruebas. En producción, usa tu propio broker (mosquitto, HiveMQ, AWS IoT, etc.).

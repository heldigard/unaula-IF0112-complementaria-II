🎯 Objetivos de Aprendizaje

Al completar este ejercicio, seras capaz de:

  • Comprender la relacion entre Personas, Procesos, Datos y Cosas en un sistema IoT

  • Entender el flujo de informacion: sensor (boton) → procesamiento (ESP32) → actuador (LED)

📦 Materiales Necesarios

En Wokwi, necesitaremos los siguientes componentes virtuales:

Componente Pin en ESP32 Funcion en IoT
ESP32 - El "cerebro" que procesa datos y ejecuta el codigo
LED ( Rojo ) Pin D2 Actuador: convierte datos electricos en luz visible

📋 Pasos del Ejercicio

1

Abrir Wokwi y crear nuevo proyecto

Ve a wokwi.com/esp32 y haz clic en "New Project". Selecciona "ESP32" como placa base.

2

Agregar los componentes

En el panel izquierdo, busca y agrega estos componentes uno por uno: LED, Resistencia (220ohm), Boton, Resistencia (10kohm).

3

Conectar el LED

Conecta el anodo (+) del LED al Pin D2 del ESP32. Conecta el catodo (-) del LED a una resistencia de 220Ω, y la resistencia a GND del ESP32.

4

Conectar el botón (4 terminales)

El botón tiene 4 terminales etiquetadas como 1.l, 1.r, 2.l y 2.r. En Wokwi las verás al pasar el mouse sobre el botón:

🔍 Entendiendo las 4 terminales:
  • 1.l y 2.l = Terminales del lado LEFT (IZQUIERDO) → conectadas internamente
  • 1.r y 2.r = Terminales del lado RIGHT (DERECHO) → conectadas internamente
  • 1.l y 1.r = Terminales en diagonal (NO conectadas)
  • 2.l y 2.r = Terminales en diagonal (NO conectadas)
Conexión paso a paso:
  1. Pin D4 del ESP32 → Conecta a terminal 1.l (lado izquierdo)
  2. Terminal 1.r (lado derecho, diagonal a 1.l) → Conecta a un extremo de la resistencia 10kΩ
  3. Otro extremo de 10kΩ → Conecta a GND del ESP32
  4. Terminal 2.l (lado izquierdo, debajo de 1.l) → Conecta a 3.3V del ESP32
⚠️ Importante: NO conectes 1.l con 2.l (mismo lado) ni 1.r con 2.r (mismo lado). Siempre usa UNA del lado izquierdo y UNA del lado derecho.
💡 Configuración correcta: 1.l (D4) + 1.r (10kΩ→GND) + 2.l (3.3V). La terminal 2.r queda libre.
5

Copiar el codigo

Copia el codigo completo de la siguiente seccion y pegalo en el editor de Wokwi (reemplazando cualquier codigo existente).

6

Ejecutar la simulacion

Haz clic en el boton verde ▶ "Start Simulation" para cargar el codigo en el ESP32 virtual y ver el LED responder al boton.

Diagrama de conexion esperado en Wokwi:

D4 → 1.r | 10kΩ → 2.r 3.3V → 1.l | GND → 2.l Leyenda D2→LED D4→Botón 3.3V GND 🚀 Abrir Wokwi Simulator

💻 Codigo Completo

Copia y pega este codigo directamente en el editor de Wokwi:

// ============================================
// EJERCICIO WOKWI 01: LED INTERACTIVO
// Semana 1 - Clase 2: Personas, Procesos, Datos y Cosas en IoT
// ============================================

// Definicion de pines - "COSAS" del sistema IoT
#define LED_PIN    2    // Pin donde esta conectado el LED (D2)
#define BUTTON_PIN 4    // Pin donde esta conectado el boton (D4)

void setup() {
  // Configuracion inicial - "PROCESOS" del sistema
  // El LED es una SALIDA: el ESP32 enviara senales al LED
  pinMode(LED_PIN, OUTPUT);

  // El boton es una ENTRADA: el ESP32 leera senales del boton
  pinMode(BUTTON_PIN, INPUT);
}

void loop() {
  // "DATOS": Lectura del estado del boton
  // digitalRead() lee el valor actual del pin (HIGH = 3.3V, LOW = 0V)
  int estadoBoton = digitalRead(BUTTON_PIN);

  // "PROCESO": Logica de decision
  // Si el boton esta presionado (HIGH), enciende el LED
  // Si el boton no esta presionado (LOW), apaga el LED
  if (estadoBoton == HIGH) {
    digitalWrite(LED_PIN, HIGH);   // Enciende el LED (envia 3.3V)
  } else {
    digitalWrite(LED_PIN, LOW);    // Apaga el LED (envia 0V)
  }

  // Pequena pausa para estabilidad
  delay(100);
}
💡 Tip: Puedes copiar el codigo haciendo clic en el boton de copiar en la esquina superior derecha del bloque de codigo, o seleccionando todo el texto manualmente.

🔍 Explicacion Detallada del Codigo

Vamos a analizar cada parte del codigo para entender como funciona el sistema IoT:

Linea 7-8: Definicion de Pines

1 #define LED_PIN 2
Proposito: Asigna un nombre facil de recordar al pin fisico D2.
IoT: Esta linea "etiqueta" la COSA fisica (el LED) para que el codigo pueda comunicarse con ella.
Analogia: Es como guardar un numero telefonico bajo un nombre en tu lista de contactos.

Lineas 13-17: Funcion setup()

2 pinMode(LED_PIN, OUTPUT);
Proposito: Configura el pin D2 como SALIDA (OUTPUT).
IoT: Le dice al ESP32 que envie datos hacia el LED (energia electrica).
Importante: Un pin configurado como OUTPUT puede enviar senales electricas para controlar dispositivos.
3 pinMode(BUTTON_PIN, INPUT);
Proposito: Configura el pin D4 como ENTRADA (INPUT).
IoT: Le dice al ESP32 que espere recibir datos del boton.
Analogia: Es como poner tu telefono en modo "recibir llamada" en lugar de "hacer llamada".

Lineas 20-30: Funcion loop()

4 int estadoBoton = digitalRead(BUTTON_PIN);
Proposito: Lee el estado actual del boton y lo guarda en una variable.
IoT: Esta es la etapa de "CAPTURA DE DATOS". El ESP32 esta leyendo informacion del sensor (el boton).
Valores posibles: HIGH (3.3V = boton presionado) o LOW (0V = boton no presionado).
5 if (estadoBoton == HIGH) { digitalWrite(LED_PIN, HIGH); }
Proposito: Si el boton esta presionado, envia senal al LED para que se encienda.
IoT: Esta es la etapa de "PROCESAMIENTO" y "ACTUACION". Se toma una decision basada en los datos capturados.
Efecto: El pin D2 recibe 3.3V, corriente fluye por el LED, y este emite luz.
6 else { digitalWrite(LED_PIN, LOW); }
Proposito: Si el boton NO esta presionado, apaga el LED.
IoT: El sistema "regresa al estado de reposo" cuando no hay interaccion.
Efecto: El pin D2 recibe 0V, no hay corriente, el LED permanece apagado.
7 delay(100);
Proposito: Espera 100 milisegundos antes de repetir el ciclo.
IoT: Controla la frecuencia de actualizacion del sistema. Un delay muy pequeno puede causar lecturas erraticas.
Nota: En sistemas IoT avanzados, usariamos "interrupciones" en lugar de delay para mayor eficiencia.

✅ Como Verificar que Funciona

Sigue esta lista de verificacion para confirmar que tu sistema IoT funciona correctamente:

  • Compilacion exitosa: No aparecen errores rojos en la consola de Wokwi al cargar el codigo
  • LED apagado inicialmente: El LED permanece apagado cuando inicias la simulacion
  • LED se enciende al presionar: Haz clic en el boton en la simulacion y verifica que el LED se ilumine
  • LED se apaga al soltar: Suelta el boton y confirma que el LED se apague
  • Respuesta rapida: El LED reacciona inmediatamente (maximo 100ms de delay)
⚠️ Solucion de problemas comunes:
  • Si el LED no enciende: Verifica que la resistencia este conectada correctamente (220Ω)
  • Si el LED siempre esta encendido: Revisa la conexion del boton a GND
  • Si el LED parpadea erraticamente: Verifica las conexiones del boton

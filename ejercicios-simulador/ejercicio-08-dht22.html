🌡️ Ejercicio 8: Sensor DHT22 - Temperatura y Humedad

⏱️ 40 min | 📦 DHT22 + Resistencia | 🟠 Medio

🎯 Objetivo

Aprender a usar el sensor DHT22 (también conocido como AM2302) para medir temperatura y humedad ambiental. Este es un sensor fundamental en proyectos IoT de monitoreo ambiental.

💡 Aplicación real: El DHT22 se usa en estaciones meteorológicas caseras, sistemas de control climático, invernaderos inteligentes, y monitoreo de bodegas.

📋 Diagrama de Conexión

Componentes Necesarios:

  • 1 x Sensor DHT22 (AM2302)
  • 1 x Resistencia 10kΩ (pull-up obligatoria)
  • Cables de conexión

Pasos de Conexión Detallados:

1 Identificar las patillas del DHT22:
  • Visto de frente (con la rejilla hacia ti):
  • Pin 1 (izquierda): VCC (3.3V o 5V)
  • Pin 2: DATA (señal de datos)
  • Pin 3: NC (No conectar - no se usa)
  • Pin 4 (derecha): GND (tierra)
2 Conectar alimentación:
  • Pin 1 (VCC) del DHT22 → 3.3V del ESP32
  • Pin 4 (GND) del DHT22 → GND del ESP32
3 Conectar señal de datos (IMPORTANTE):
  • Pin 2 (DATA) del DHT22 → GPIO 4 del ESP32
  • Colocar resistencia 10kΩ entre Pin 2 (DATA) y Pin 1 (VCC)
  • Esta resistencia es obligatoria para estabilizar la señal
⚠️ Importante:
  • El DHT22 requiere resistencia pull-up de 4.7kΩ a 10kΩ entre DATA y VCC
  • Sin esta resistencia, las lecturas serán erráticas o mostrarán "nan"
  • El DHT22 puede funcionar con 3.3V o 5V (usamos 3.3V para compatibilidad con ESP32)
  • El sensor tiene una tasa de muestreo de 2 segundos - no leer más frecuentemente
  • El pin 3 (NC) no se conecta a nada
💡 Diferencia entre DHT11 y DHT22:
  • DHT11: Menor precisión (±2°C, ±5% HR), rango limitado (0-50°C)
  • DHT22 (AM2302): Mayor precisión (±0.5°C, ±2% HR), rango amplio (-40 a 80°C)
  • El curso usa DHT22 por su mejor precisión para proyectos IoT profesionales

📋 Código

// Ejercicio 8: Sensor DHT22 - Temperatura y Humedad
// Requiere instalar la librería: "DHT sensor library" by Adafruit

#include "DHT.h"

// Definiciones del sensor
#define DHTPIN 4        // Pin GPIO conectado al DATA del DHT22
#define DHTTYPE DHT22   // Tipo de sensor (DHT22 o AM2302)

// Crear objeto DHT
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  Serial.println("=== Ejercicio 8: Sensor DHT22 ===");
  Serial.println("Iniciando sensor DHT22...");

  // Inicializar el sensor
  dht.begin();

  Serial.println("Sensor iniciado. Esperando 2 segundos...");
  delay(2000); // El DHT22 necesita tiempo para estabilizarse
}

void loop() {
  // Esperar 2 segundos entre lecturas (obligatorio para DHT22)
  delay(2000);

  // Leer temperatura y humedad
  float humedad = dht.readHumidity();
  float temperatura = dht.readTemperature(); // Por defecto en Celsius

  // Verificar si la lectura falló
  if (isnan(humedad) || isnan(temperatura)) {
    Serial.println("⚠️ Error: Fallo al leer del sensor DHT22!");
    Serial.println("   Verifica las conexiones y la resistencia pull-up.");
    return;
  }

  // Calcular índice de calor (sensación térmica)
  float indiceCalor = dht.computeHeatIndex(temperatura, humedad, false);

  // Mostrar resultados
  Serial.println("\n--- Lectura DHT22 ---");
  Serial.print("Humedad: ");
  Serial.print(humedad);
  Serial.println(" %");

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" °C");

  Serial.print("Sensación térmica: ");
  Serial.print(indiceCalor);
  Serial.println(" °C");

  // Interpretación de humedad
  Serial.print("Estado: ");
  if (humedad < 30) {
    Serial.println("💨 Aire seco");
  } else if (humedad > 70) {
    Serial.println("💧 Aire húmedo");
  } else {
    Serial.println("✅ Humedad confortable");
  }

  Serial.println("---------------------");
}

🔍 Conceptos Clave

Librería DHT

La librería DHT.h simplifica la comunicación con el sensor:

  • dht.begin(): Inicializa el sensor en setup()
  • dht.readHumidity(): Lee humedad relativa (0-100%)
  • dht.readTemperature(): Lee temperatura en °C
  • dht.computeHeatIndex(): Calcula sensación térmica
  • isnan(): Verifica si la lectura es válida (not-a-number)

Protocolo de Comunicación

El DHT22 usa un protocolo propietario de 1-wire (no es el mismo que Dallas 1-Wire):

  • Transmite 40 bits de datos (16 humedad, 16 temperatura, 8 checksum)
  • La resistencia pull-up mantiene la línea en HIGH cuando no transmite
  • El ESP32 envía una señal de inicio, el DHT22 responde con datos

🔧 Solución de Problemas

Problema Causa probable Solución
Lectura "nan" Sin resistencia pull-up Agregar 10kΩ entre DATA y VCC
Lecturas erráticas Lecturas muy frecuentes Esperar mínimo 2 segundos entre lecturas
Valores incorrectos DHTTYPE incorrecto Verificar que sea DHT22, no DHT11
No compila Falta librería Instalar "DHT sensor library" de Adafruit

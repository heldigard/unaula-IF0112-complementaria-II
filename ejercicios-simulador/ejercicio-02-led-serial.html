📡 Ejercicio 2: LED + Monitor Serial

⏱️ 20 min | 📦 1 LED | 🟡 Fácil

🎯 Objetivo

Aprender a usar el Monitor Serial para depurar y visualizar datos de tu programa ESP32.

🔌 Diagrama de Conexión

Componentes Necesarios

  • 1x LED (cualquier color)
  • 1x Resistencia de 220Ω
  • ESP32

Conexiones

Componente Pin ESP32
Ánodo del LED (pata larga) GPIO 18
Cátodo del LED (pata corta) Resistencia 220Ω → GND

Diagrama del Circuito

    ESP32                    LED + Resistencia
    ┌─────┐               ┌──────────────┐
    │     │               │              │
    │ GPIO│───────────────┤ ÁNODO (+)    │
    │  18 │               │        │      │
    │     │               │       LED     │
    │ GND │───────────┐   │        │      │
    │     │           │   │ CÁTODO (-)   │
    └─────┘           │   │              │
                      │   └──────────────┘
                      │
                     ┌┴┐
                     │R│ 220Ω
                     └┬┘
                      │
                     GND
💡 Nota Importante:
  • Este ejercicio usa el mismo circuito del Ejercicio 1 (LED Blink)
  • El ánodo es la pata larga del LED (va hacia el pin del ESP32)
  • El cátodo es la pata corta del LED (va hacia GND)
  • La resistencia siempre se conecta en serie con el LED para limitar la corriente
  • Sin resistencia, el LED puede quemarse o dañar el ESP32

📋 Código

// Ejercicio 2: LED con Monitor Serial
const int ledPin = 18;
unsigned long ultimoCambio = 0;
int estadoLed = LOW;
int contador = 0;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);

  Serial.println("=== INICIO DEL PROGRAMA ===");
  Serial.println("Ejercicio 2: Monitor Serial");
  Serial.println("Presiona Ctrl+Shift+M para abrir el Monitor Serial");
  Serial.println();
}

void loop() {
  unsigned long tiempoActual = millis();

  // Cambiar LED cada segundo sin usar delay()
  if (tiempoActual - ultimoCambio >= 1000) {
    ultimoCambio = tiempoActual;

    // Cambiar estado del LED
    estadoLed = !estadoLed;
    digitalWrite(ledPin, estadoLed);

    // Incrementar contador
    contador++;

    // Enviar información al Monitor Serial
    Serial.print("Ciclo #");
    Serial.print(contador);
    Serial.print(" | LED: ");
    Serial.println(estadoLed == HIGH ? "ENCENDIDO 💡" : "APAGADO");

    // Mostrar tiempo transcurrido
    Serial.print("Tiempo: ");
    Serial.print(tiempoActual / 1000);
    Serial.println(" segundos");
    Serial.println("---");
  }
}

🔍 Lo Nuevo en Este Ejercicio

1. millis()

Devuelve el número de milisegundos desde que inició el programa. Es mejor que delay() porque no bloquea el procesador.

2. Serial.print() vs Serial.println()
  • Serial.print(): Imprime SIN salto de línea
  • Serial.println(): Imprime CON salto de línea
3. Operador Ternario 
estadoLed == HIGH ? "ENCENDIDO" : "APAGADO"

Es una forma compacta de un if-else. Equivale a:

if (estadoLed == HIGH) {
  return "ENCENDIDO";
} else {
  return "APAGADO";
}

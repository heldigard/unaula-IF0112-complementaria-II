🤝 Ejercicio 16: M2M Simulation

⏱️ 30 min | 📦 ESP32 + 2 LEDs | 🟠 Medio

🎯 Objetivo

Simular comunicación Machine-to-Machine (M2M) donde un dispositivo (sensor) envía datos a otro dispositivo (actuador) de forma autónoma, sin intervención humana.

💡 Contexto: M2M es la base del IoT industrial. Permite que máquinas se comuniquen directamente: un sensor de temperatura puede activar un ventilador automáticamente.

📚 Tipos de Comunicación IoT

TipoDescripciónEjemplo
M2MMáquina a MáquinaSensor → Actuador
M2PMáquina a PersonaAlerta → Smartphone
P2MPersona a MáquinaApp → Encender luz
P2PPersona a Persona (vía IoT)Compartir datos de salud

En este ejercicio simulamos M2M: un módulo sensor detecta luz y envía comandos a un módulo actuador que controla un LED.

📋 Diagrama de Conexión

Componentes:

  • 1 x ESP32 DevKit V1
  • 1 x LDR (fotorresistencia) + Resistencia 10kΩ
  • 2 x LEDs (uno representa "sensor", otro "actuador")
  • 2 x Resistencias 220Ω

Conexiones:

LDR (Sensor):
  Un lado → 3.3V
  Otro lado → GPIO34 + Resistencia 10kΩ
  Resistencia 10kΩ → GND

LED Sensor (indicador de estado):
  GPIO2 → 220Ω → LED → GND

LED Actuador (responde a comandos):
  GPIO18 → 220Ω → LED → GND

📋 Código: Simulación M2M

// Ejercicio 16: M2M Simulation - Comunicación Machine-to-Machine
// Simula dos módulos comunicándose: SENSOR → ACTUADOR

const int ldrPin = 34;
const int ledSensorPin = 2;   // LED del módulo sensor
const int ledActuadorPin = 18; // LED del módulo actuador

// Simulación de cola de mensajes M2M
#define MAX_MESSAGES 5
String messageQueue[MAX_MESSAGES];
int queueHead = 0;
int queueTail = 0;

// Umbrales
const int UMBRAL_OSCURO = 30;   // % luz para considerar oscuro
const int UMBRAL_BRILLANTE = 70; // % luz para considerar brillante

// Estados
enum EstadoLuz { DESCONOCIDO, OSCURO, NORMAL, BRILLANTE };
EstadoLuz estadoActual = DESCONOCIDO;
EstadoLuz estadoAnterior = DESCONOCIDO;

unsigned long ultimoMensaje = 0;
const long INTERVALO_MENSAJE = 2000; // 2 segundos

// Función para simular envío de mensaje M2M
void enviarMensajeM2M(String mensaje) {
  if ((queueTail + 1) % MAX_MESSAGES != queueHead) {
    messageQueue[queueTail] = mensaje;
    queueTail = (queueTail + 1) % MAX_MESSAGES;
    Serial.print("📤 M2M TX: ");
    Serial.println(mensaje);
  }
}

// Función para simular recepción de mensaje M2M
String recibirMensajeM2M() {
  if (queueHead != queueTail) {
    String mensaje = messageQueue[queueHead];
    queueHead = (queueHead + 1) % MAX_MESSAGES;
    return mensaje;
  }
  return "";
}

// Función del Módulo Sensor
void moduloSensor() {
  int lectura = analogRead(ldrPin);
  int lux = map(lectura, 0, 4095, 0, 100);

  // Determinar estado
  EstadoLuz nuevoEstado;
  if (lux < UMBRAL_OSCURO) {
    nuevoEstado = OSCURO;
    digitalWrite(ledSensorPin, HIGH);  // LED sensor on = oscuro
  } else if (lux > UMBRAL_BRILLANTE) {
    nuevoEstado = BRILLANTE;
    digitalWrite(ledSensorPin, LOW);
  } else {
    nuevoEstado = NORMAL;
    digitalWrite(ledSensorPin, LOW);
  }

  // Si cambió el estado, enviar mensaje M2M
  if (nuevoEstado != estadoAnterior) {
    String mensaje = "";
    switch (nuevoEstado) {
      case OSCURO:
        mensaje = "CMD:LED_ON|RZN:LOW_LIGHT";
        break;
      case BRILLANTE:
        mensaje = "CMD:LED_OFF|RZN:HIGH_LIGHT";
        break;
      case NORMAL:
        mensaje = "CMD:LED_OFF|RZN:NORMAL";
        break;
    }
    enviarMensajeM2M(mensaje);
    estadoAnterior = nuevoEstado;
  }

  estadoActual = nuevoEstado;
}

// Función del Módulo Actuador
void moduloActuador() {
  String mensaje = recibirMensajeM2M();

  if (mensaje != "") {
    Serial.print("📥 M2M RX: ");
    Serial.println(mensaje);

    // Parsear comando M2M
    if (mensaje.indexOf("CMD:LED_ON") >= 0) {
      digitalWrite(ledActuadorPin, HIGH);
      Serial.println("💡 ACTUADOR: LED encendido (comando M2M)");
    }
    else if (mensaje.indexOf("CMD:LED_OFF") >= 0) {
      digitalWrite(ledActuadorPin, LOW);
      Serial.println("💡 ACTUADOR: LED apagado (comando M2M)");
    }
  }
}

void setup() {
  pinMode(ledSensorPin, OUTPUT);
  pinMode(ledActuadorPin, OUTPUT);
  Serial.begin(115200);

  Serial.println("=== M2M Simulation ===");
  Serial.println("Módulo 1: SENSOR (LDR + LED indicador)");
  Serial.println("Módulo 2: ACTUADOR (LED controlado)");
  Serial.println("----------------------------------------");
}

void loop() {
  // Ejecutar módulos (simulan dispositivos separados)
  moduloSensor();
  moduloActuador();

  // Status periódico
  if (millis() - ultimoMensaje > INTERVALO_MENSAJE) {
    Serial.print("📊 Estado: ");
    switch (estadoActual) {
      case OSCURO: Serial.print("🌙 OSCURO"); break;
      case NORMAL: Serial.print("🌤️ NORMAL"); break;
      case BRILLANTE: Serial.print("☀️ BRILLANTE"); break;
      default: Serial.print("❓ DESCONOCIDO");
    }
    Serial.println(" | M2M activo");
    ultimoMensaje = millis();
  }

  delay(100);
}

🔍 Cómo Funciona la Simulación

📡 Módulo Sensor

  • Lee LDR continuamente
  • Detecta cambios de luz
  • Envía comandos M2M
  • LED indica estado local

💡 Módulo Actuador

  • Recibe mensajes M2M
  • Parsea comandos
  • Ejecuta acciones
  • LED responde a comandos
💡 Observa: Ambos "módulos" se ejecutan en el mismo ESP32, pero la arquitectura simula dos dispositivos separados comunicándose por una cola de mensajes. En un caso real, serían dos ESP32 diferentes conectados por WiFi, MQTT o Serial.

📸 Instrucciones de Entrega

  1. Ejecuta la simulación
  2. Tapa el LDR (simula oscuridad)
  3. Observa el Monitor Serial mostrando mensajes M2M
  4. Verifica que el LED actuador responde a los comandos
  5. Toma pantallazo del Monitor Serial con mensajes M2M
  6. Sube a Canvas

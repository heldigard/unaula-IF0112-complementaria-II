⏱️ Ejercicio 8: Timer - Multitarea Real

⏱️ 40 min | 📦 2 LEDs | 🔴 Avanzado

🎯 Objetivo

Aprender a usar timers del ESP32 para hacer multitarea real sin usar delay(). Los dos LEDs parpadearán a velocidades diferentes simultáneamente.

💡 ¿Por qué evitar delay()? delay() bloquea el procesador. Con timers, el ESP32 puede hacer múltiples cosas al mismo tiempo.

📋 Diagrama de Conexión

Componentes Necesarios:

  • 2 x LEDs (pueden ser colores diferentes)
  • 2 x Resistencias 220Ω o 330Ω
  • Cables de conexión

Conexiones:

LED 1 (Parpadeo Rápido - 0.5s):

  • Ánodo (+) → Pin D18 (vía resistor 220Ω)
  • Cátodo (-) → Pin GND

LED 2 (Parpadeo Lento - 1.5s):

  • Ánodo (+) → Pin D19 (vía resistor 220Ω)
  • Cátodo (-) → Pin GND

Diagrama ASCII:

LED 1 (rápido):          LED 2 (lento):
ESP32 D18 ──[220Ω]──[LED]─┐
                            │
                           GND
ESP32 D19 ──[220Ω]──[LED]─┘
💡 Nota Importante: El circuito es simple (dos LEDs independientes). La complejidad de este ejercicio está en el código, que usa timers del ESP32 para hacer multitarea real sin usar delay().

Verificación de Conexión:

Antes de cargar el código del timer, verifica que ambos LEDs funcionen correctamente con un código simple de prueba:

void setup() {
  pinMode(18, OUTPUT);
  pinMode(19, OUTPUT);
}

void loop() {
  digitalWrite(18, HIGH);
  digitalWrite(19, HIGH);
  delay(500);
  digitalWrite(18, LOW);
  digitalWrite(19, LOW);
  delay(500);
}

Si ambos LEDs parpadean al mismo tiempo, las conexiones son correctas.

📋 Código

// Ejercicio 8: Timers - Multitarea sin delay()
#include <WiFi.h>  // Para hw_timer_t

const int led1Pin = 18;  // LED rápido
const int led2Pin = 19;  // LED lento

volatile bool cambiarLed1 = false;
volatile bool cambiarLed2 = false;

hw_timer_t *timer1 = NULL;
hw_timer_t *timer2 = NULL;

// Función de interrupción para Timer 1
void IRAM_ATTR timer1ISR() {
  cambiarLed1 = true;
}

// Función de interrupción para Timer 2
void IRAM_ATTR timer2ISR() {
  cambiarLed2 = true;
}

void setup() {
  pinMode(led1Pin, OUTPUT);
  pinMode(led2Pin, OUTPUT);

  Serial.begin(115200);
  Serial.println("=== Ejercicio 8: Multitarea con Timers ===");

  // Timer 1: LED rápido (cada 500ms)
  timer1 = timerBegin(0, 80, true);  // Prescaler 80
  timerAttachInterrupt(timer1, &timer1ISR);
  timerAlarmWrite(timer1, 500000, true);  // 500ms en microsegundos
  timerAlarmEnable(timer1);

  // Timer 2: LED lento (cada 1500ms)
  timer2 = timerBegin(1, 80, true);
  timerAttachInterrupt(timer2, &timer2ISR);
  timerAlarmWrite(timer2, 1500000, true);  // 1500ms
  timerAlarmEnable(timer2);

  Serial.println("Timers iniciados!");
  Serial.println("LED 1 parpadea cada 0.5s");
  Serial.println("LED 2 parpadea cada 1.5s");
}

void loop() {
  if (cambiarLed1) {
    cambiarLed1 = false;
    digitalWrite(led1Pin, !digitalRead(led1Pin));
    Serial.println("LED 1 cambió");
  }

  if (cambiarLed2) {
    cambiarLed2 = false;
    digitalWrite(led2Pin, !digitalRead(led2Pin));
    Serial.println("LED 2 cambió");
  }
}

🔍 Conceptos Avanzados

Interrupciones

Una interrupción es un evento que pausa el programa normal para ejecutar código específico. Los timers generan interrupciones automáticamente.

  • timerBegin(): Inicia un timer hardware
  • timerAttachInterrupt(): Conecta una función al timer
  • timerAlarmWrite(): Configura cuándo disparar
  • IRAM_ATTR: Pone código en RAM (más rápido)

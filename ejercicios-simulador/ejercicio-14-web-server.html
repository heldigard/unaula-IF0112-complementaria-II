🌐 Ejercicio 14: Web Server ESP32

⏱️ 35 min | 📦 ESP32 + LED | 🔴 Avanzado

🎯 Objetivo

Crear un servidor web básico en el ESP32 que permita controlar un LED desde el navegador usando WiFi.p>

📚 Conceptos Clave que Aprenderás:
ConceptoDescripción
Web ServerServidor HTTP que sirve páginas web desde el ESP32
HTTPProtocolo de transferencia de Hypertext (base de la Web)
WiFi ServerClase que permite crear un servidor TCP en el ESP32
WiFiClientClase para manejar conexiones de clientes HTTP
Petición HTTPMensaje que envía los clientes al servidor
💡 Contexto: Un Web Server embebido permite controlar dispositivos IoT desde cualquier navegador, sin necesidad de apps adicionales. Es la base de muchos sistemas de domótica como Home Assistant, Tasmota, y ESPHome.

📋 Diagrama de Conexión

Componentes:

  • 1 x ESP32 DevKit V1
  • 1 x LED (o usa el LED integrado en GPIO 2)
  • 1 x Resistencia 220Ω (si usas LED externo)

Conexión:

LED externo:
  GPIO 2 → 220Ω → Ánodo LED → Cátodo LED → GND

O usa el LED integrado del ESP32 (GPIO 2)

📋 Código: Web Server Básico

// Ejercicio 14: Web Server ESP32 - Control LED por WiFi
#include <WiFi.h>

// Credenciales WiFi (Wokwi usa estas por defecto)
const char* ssid = "Wokwi-GUEST";
const char* password = "";

// Configuración del servidor
WiFiServer server(80);

// Variables
const int ledPin = 2;
String header;
String ledState = "off";

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, LOW);

  // Conectar a WiFi
  Serial.print("Conectando a ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("");
  Serial.println("WiFi conectado!");
  Serial.print("IP del servidor: ");
  Serial.println(WiFi.localIP());

  // Iniciar servidor
  server.begin();
}

void loop() {
  WiFiClient client = server.available();

  if (client) {
    Serial.println("Nuevo cliente conectado");
    String currentLine = "";

    while (client.connected()) {
      if (client.available()) {
        char c = client.read();
        header += c;

        if (c == '\n') {
          if (currentLine.length() == 0) {
            // Enviar respuesta HTTP
            client.println("HTTP/1.1 200 OK");
            client.println("Content-type:text/html");
            client.println("Connection: close");
            client.println();

            // Procesar comandos
            if (header.indexOf("GET /on") >= 0) {
              Serial.println("GPIO 2 ON");
              ledState = "on";
              digitalWrite(ledPin, HIGH);
            }
            else if (header.indexOf("GET /off") >= 0) {
              Serial.println("GPIO 2 OFF");
              ledState = "off";
              digitalWrite(ledPin, LOW);
            }

            // Enviar página HTML
            client.println("<!DOCTYPE html>");
            client.println("<html>");
            client.println("<head>");
            client.println("<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">");
            client.println("<title>ESP32 Web Server</title>");
            client.println("<style>");
            client.println("body { font-family: Arial; text-align: center; margin: 50px; }");
            client.println("h1 { color: #333; }");
            client.println(".button { padding: 15px 30px; font-size: 18px; margin: 10px; border: none; border-radius: 8px; cursor: pointer; }");
            client.println(".on { background: #10b981; color: white; }");
            client.println(".off { background: #ef4444; color: white; }");
            client.println("</style>");
            client.println("</head>");
            client.println("<body>");
            client.println("<h1>🌐 ESP32 Web Server</h1>");
            client.println("<p>Estado del LED: <strong>" + ledState + "</strong></p>");

            if (ledState == "off") {
              client.println("<a href=\"/on\"><button class=\"button on\">ENCENDER</button></a>");
            } else {
              client.println("<a href=\"/off\"><button class=\"button off\">APAGAR</button></a>");
            }

            client.println("</body>");
            client.println("</html>");
            client.println();
            break;
          } else {
            currentLine = "";
          }
        } else if (c != '\r') {
          currentLine += c;
        }
      }
    }

    header = "";
    client.stop();
    Serial.println("Cliente desconectado");
  }
}

🔍 Cómo Probar en Wokwi

  1. Copia el código en Wokwi
  2. Ejecuta la simulación
  3. Espera a que muestre la IP (ej: 192.168.1.100)
  4. En Wokwi, haz clic en el icono de globo o busca el embedded browser
  5. Accede a la IP mostrada desde el navegador integrado
  6. Haz clic en los botones para encender/apagar el LED
⚠️ Nota Importante: En Wokwi, el Web Server funciona en una red simulada. La IP que aparece es interna del simulador. Usa el navegador embebido de Wokwi para acceder.

📸 Instrucciones de Entrega

  1. Ejecuta la simulación y espera la IP
  2. Accede al web server desde el navegador de Wokwi
  3. Toma pantallazo de la página web funcionando
  4. Toma pantallazo del Monitor Serial mostrando las conexiones
  5. Sube ambos a Canvas

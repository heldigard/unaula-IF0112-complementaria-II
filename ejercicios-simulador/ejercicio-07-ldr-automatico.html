🌙 Ejercicio 7: LDR - Sistema Automático

⏱️ 35 min | 📦 1 LDR + 1 LED | 🟡 Fácil

🎯 Objetivo

Crear un sistema automático que enciende un LED cuando oscurece y lo apaga cuando hay luz. ¡Como una lámpara automática!

📋 Diagrama de Conexión

Componentes Necesarios:

  • 1 x LDR (fotorresistencia)
  • 1 x Resistencia 10kΩ (para pull-down del LDR)
  • 1 x LED (opcional, para visualización)
  • 1 x Resistencia 220Ω (para el LED)
  • Cables de conexión

Conexiones del LDR (Sensor de Luz):

El LDR se conecta como un divisor de tensión:

  • LDR → Un lado a 3.3V
  • LDR → Otro lado a D34 (ADC1_CH6) y a resistencia 10kΩ
  • Resistencia 10kΩ → Otro lado a GND

Conexión del LED (Opcional - para visualización):

  • Ánodo (+) del LED → Pin D18 (a través del resistor 220Ω)
  • Cátodo (-) del LED → Pin GND

Diagrama ASCII del Circuito LDR:

         3.3V
          │
          ├──[LDR]──┬── D34 (ADC1_CH6)
          │         │
          │        [10kΩ]
          │         │
         GND       GND
⚠️ Importante: El GPIO 34 (D34) es Solo Entrada en el ESP32. No puede usarse como salida. El LDR varía su resistencia según la luz: más luz = menos resistencia, menos luz = más resistencia.

Cómo Funciona el Divisor de Tensión:

El LDR y la resistencia de 10kΩ forman un divisor de tensión. Cuando hay mucha luz, el LDR tiene baja resistencia y el voltaje en D34 es alto. Cuando hay poca luz, el LDR tiene alta resistencia y el voltaje en D34 es bajo.

📋 Código

// Ejercicio 7: Sistema Automático con LDR
const int ldrPin = 34;
const int ledPin = 18;

// Umbral para encender LED (ajustar según ambiente)
const int umbral = 2000;  // Menor de 2000 = oscuro

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);

  Serial.println("=== Sistema de Iluminación Automática ===");
  Serial.println("LED se enciende cuando hay poca luz");
  Serial.print("Umbral configurado: ");
  Serial.println(umbral);
}

void loop() {
  int valorLdr = analogRead(ldrPin);

  Serial.print("Luz: ");
  Serial.print(valorLdr);

  // Lógica de control automático
  if (valorLdr < umbral) {
    digitalWrite(ledPin, HIGH);
    Serial.println(" -> OSCURO, LED encendido 💡");
  } else {
    digitalWrite(ledPin, LOW);
    Serial.println(" -> CLARO, LED apagado");
  }

  delay(1000);
}

🔧 Ajuste del Umbral

El valor del umbral depende del ambiente. Puedes ajustarlo:

  • 2000: Valor medio (aproximadamente 50% de luz)
  • 1000: Más sensible (se enciende con más luz)
  • 3000: Menos sensible (solo en oscuro)

En Wokwi, haz clic derecho en el LDR para simular diferentes niveles de luz.

☀️ Ejercicio 6: LDR - Sensor de Luz

⏱️ 30 min | 📦 1 LDR + 1 LED | 🟠 Medio

🎯 Objetivo

Aprender a leer valores analógicos de un sensor LDR (fotorresistencia) y mostrarlos en el Monitor Serial.

📋 Diagrama de Conexión

Componentes Necesarios (vérificalos antes de empezar):

  • ✅ 1 x LDR (fotorresistencia) - tiene forma de disco con líneas en espiral
  • ✅ 1 x Resistencia 10kΩ (marrón-negro-naranja) - la de color amarillo es más grande
  • ✅ 1 x LED (cualquier color - rojo, verde, azul)
  • ✅ 1 x Resistencia 220Ω (rojo-rojo-marrón) - para el LED
  • ✅ Cables de conexión (mínimo 6)
⚠️ ERROR COMÚN: No confundas la resistencia de 10kΩ (pull-down del LDR) con la de 220Ω (LED). Son muy diferentes. Si dudas, lee los colores: 220Ω = rojo-rojo-marrón, 10kΩ = marrón-negro-naranja.

Conexiones del LDR (Sensor de Luz):

El LDR se conecta como un divisor de tensión. Sigue estos pasos exactos:

  1. Paso 1: Conecta un extremo del LDR al pin 3.3V del ESP32 (cable ROJO)
  2. Paso 2: Conecta el otro extremo del LDR a:
    • Una patita de la resistencia de 10kΩ
    • Al pin GPIO34 (D34) del ESP32
  3. Paso 3: Conecta la otra patita de la resistencia de 10kΩ al pin GND del ESP32 (cable NEGRO)
⚠️ IMPORTANTE - Conexión correcta del LDR:
El LDR necesita la resistencia de 10kΩ hacia GND (no hacia VCC). Sin esta resistencia, el pin GPIO34 queda "flotando" y dará lecturas aleatorias.

Conexión del LED (Opcional - para visualización):

Si quieres ver visualmente cuándo hay poca luz:

  1. Paso 1: Conecta la resistencia de 220Ω al pin D18 del ESP32
  2. Paso 2: Conecta el ánodo (la patita larga, +) del LED a la resistencia de 220Ω
  3. Paso 3: Conecta el cátodo (la patita corta, -) del LED al pin GND del ESP32
⚠️ ERROR COMÚN - LED no enciende:
¿LED al revés? La patita LARGA va hacia la resistencia (ánodo +), la patita CORTA va a GND (cátodo -). Si lo pones al revés, no se dañará pero no funcionará.

Diagrama del Circuito:

⚠️ Importante: El GPIO 34 (D34) es Solo Entrada en el ESP32. No puede usarse como salida. El LDR varía su resistencia según la luz: más luz = menos resistencia, menos luz = más resistencia.

Cómo Funciona el Divisor de Tensión:

El LDR y la resistencia de 10kΩ forman un divisor de tensión. Cuando hay mucha luz, el LDR tiene baja resistencia y el voltaje en D34 es alto. Cuando hay poca luz, el LDR tiene alta resistencia y el voltaje en D34 es bajo.

📋 Código

// Ejercicio 6: LDR - Sensor de Luz
const int ldrPin = 34;  // ADC1_CH6 - Solo entrada analógica
const int ledPin = 18;

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(115200);

  Serial.println("=== Ejercicio 6: Sensor LDR ===");
  Serial.println("Lecturas del sensor de luz");
  Serial.println("Rango: 0 (oscuro) a 4095 (muy brillante)");
}

void loop() {
  int valorLdr = analogRead(ldrPin);

  // Convertir a porcentaje (0-100%)
  int porcentaje = map(valorLdr, 0, 4095, 0, 100);

  Serial.print("Valor LDR: ");
  Serial.print(valorLdr);
  Serial.print(" | Porcentaje: ");
  Serial.print(porcentaje);
  Serial.println("%");

  // Encender LED si hay poca luz
  if (valorLdr < 2000) {
    digitalWrite(ledPin, HIGH);
    Serial.println("-> Poca luz detectada, LED encendido");
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(500);
}

🔍 Conceptos Clave

Entradas Analógicas

  • analogRead(pin): Lee un valor de 0 a 4095 (12 bits)
  • map(valor, deMin, deMax, aMin, aMax): Convierte un rango a otro
  • El ESP32 tiene varios pines ADC: GPIO 34, 35, 36, 39 son SOLO entrada

🔍 Cómo Probar en Wokwi (Paso a Paso)

  1. Paso 1: Ve a wokwi.com y crea un nuevo proyecto con ESP32
  2. Paso 2: Copia y pega el código en el editor de Wokwi
  3. Paso 3: Agrega los componentes:
    • 1 LDR (busca "photoresistor" en los componentes)
    • 1 Resistencia de 10kΩ (en resistors, busca "10000" ohms)
    • 1 LED (cualquier color)
    • 1 Resistencia de 220Ω (en resistors, busca "220" ohms)
  4. Paso 4: Conecta todo según el diagrama SVG de arriba
  5. Paso 5: Haz clic en el botón verde ▶️ "Start Simulation"
  6. Paso 6: Abre el Monitor Serial (botón de la derecha, icono de consola)
  7. Paso 7: En el simulador, haz clic derecho sobre el LDR y selecciona:
    • "Bright" (brillante) → Valor alto (~3000-4000)
    • "Dim" (tenue) → Valor medio (~1500-2500)
    • "Dark" (oscuro) → Valor bajo (~0-1000)
  8. Paso 8: Observa los valores. Cuando el valor baje de 2000, el LED se enciende automáticamente
⚠️ NO VES NADA EN EL MONITOR SERIAL?
Verifica que esté configurado en 115200 baudios. Ese es el valor correcto en el código.

🔧 Problemas Comunes y Soluciones

Problema Causa Solución
Valores siempre en 0 o 4095 LDR mal conectado Verifica que el LDR tenga la resistencia 10kΩ hacia GND
LED no enciende nunca LED al revés o resistencia muy alta Invierte las patitas del LED (larga = +)
Valores muy inestables Conexiones flojas Revisa que todos los cables estén bien conectados
"GPIO34 is not an output" Usas pin 34 como salida GPIO34 solo es entrada. Usa otro pin para el LED (D18)

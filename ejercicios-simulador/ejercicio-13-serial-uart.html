📡 Ejercicio 13: Comunicación Serial UART

⏱️ 25 min | 📦 Solo ESP32 | 🟢 Básico

🎯 Objetivo

Aprender a enviar y recibir datos a través del puerto serial (UART) del ESP32, el protocolo de comunicación más básico en sistemas embebidos.

💡 Contexto: UART (Universal Asynchronous Receiver-Transmitter) es el protocolo que usas cada vez que ves el Monitor Serial. Es la base de muchas comunicaciones en IoT.

📚 Conceptos Previos

¿Qué es UART?

UART es un protocolo de comunicación serial asíncrono que permite enviar datos bit por bit:

ParámetroValor típicoDescripción
Baud Rate9600, 115200Velocidad de transmisión (bits/segundo)
Data Bits8Cantidad de bits por carácter
ParidadNoneBit de verificación (opcional)
Stop Bits1Bit que indica fin de transmisión

Funciones Principales

  • Serial.begin(115200) - Inicia comunicación a 115200 baudios
  • Serial.print("texto") - Envía texto sin salto de línea
  • Serial.println("texto") - Envía texto con salto de línea
  • Serial.available() - Retorna cantidad de bytes disponibles
  • Serial.read() - Lee un byte del buffer
  • Serial.readString() - Lee string completo hasta timeout

📋 Código: Eco Serial con Comandos

// Ejercicio 13: Comunicación Serial UART
// Recibe comandos y responde

String comando = "";
bool ledEstado = false;

void setup() {
  Serial.begin(115200);
  pinMode(2, OUTPUT);  // LED integrado

  Serial.println("=== Ejercicio 13: Comunicación Serial UART ===");
  Serial.println("Comandos disponibles:");
  Serial.println("  ON    - Encender LED");
  Serial.println("  OFF   - Apagar LED");
  Serial.println("  STATUS - Ver estado del LED");
  Serial.println("  HOLA  - Saludo");
  Serial.println("  HELP  - Mostrar ayuda");
  Serial.println("------------------------------------");
  Serial.print("> ");
}

void loop() {
  // Verificar si hay datos disponibles
  if (Serial.available() > 0) {
    // Leer el comando hasta salto de línea
    comando = Serial.readStringUntil('\n');
    comando.trim();  // Eliminar espacios y saltos
    comando.toUpperCase();  // Convertir a mayúsculas

    Serial.println(comando);  // Eco del comando

    // Procesar comando
    if (comando == "ON") {
      ledEstado = true;
      digitalWrite(2, HIGH);
      Serial.println("✅ LED ENCENDIDO");
    }
    else if (comando == "OFF") {
      ledEstado = false;
      digitalWrite(2, LOW);
      Serial.println("❌ LED APAGADO");
    }
    else if (comando == "STATUS") {
      Serial.print("📊 Estado LED: ");
      Serial.println(ledEstado ? "ENCENDIDO" : "APAGADO");
    }
    else if (comando == "HOLA") {
      Serial.println("👋 ¡Hola! Soy tu ESP32");
    }
    else if (comando == "HELP") {
      Serial.println("📋 Comandos: ON, OFF, STATUS, HOLA, HELP");
    }
    else {
      Serial.print("⚠️ Comando no reconocido: ");
      Serial.println(comando);
      Serial.println("   Escribe HELP para ver comandos");
    }

    Serial.print("> ");
  }
}

🔍 Cómo Probar en Wokwi

  2. Abre el Monitor Serial (icono de terminal)
  3. Escribe comandos en el campo de entrada: ON, OFF, STATUS, HOLA
  4. Observa cómo el LED responde y el ESP32 confirma cada acción
⚠️ Nota: En Wokwi, el Monitor Serial muestra la salida pero para enviar comandos debes usar el campo de entrada que aparece en la parte inferior del monitor.

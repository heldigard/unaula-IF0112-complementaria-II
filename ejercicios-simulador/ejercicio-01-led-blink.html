💡 Ejercicio 1: LED Parpadeante

⏱️ Duración: 15 minutos | 📦 Componentes: 1 LED | 🟢 Nivel: Básico

🎯 Objetivo

Aprenderás los fundamentos de la programación del ESP32 haciendo que un LED parpadee. Este es el "Hola Mundo" de la electrónica y te introducirá en:

  • Estructura básica de un programa Arduino
  • Funciones setup() y loop()
  • Configuración de pines digitales
  • Control de tiempo con delay()

📦 Componentes Necesarios

En el simulador Wokwi, agregarás estos componentes:

💡
1 x LED (Cualquier color)
⚡
1 x Resistor 220Ω
🔌
Cables de conexión
🚀 Abrir Wokwi ESP32 Simulator

📋 Instrucciones Paso a Paso

1 Abrir el Simulador

Abre wokwi.com/esp32 en una nueva pestaña. Verás el ESP32 ya colocado en el área de trabajo.

2 Agregar el LED

En el panel izquierdo, haz clic en + junto a "LED" o arrastra un LED desde la lista de componentes al área de trabajo.

💡 Tip: También puedes escribir "+led" en el código y aparecerá el LED automáticamente.
3 Conectar el LED al ESP32

Conecta los componentes siguiendo el diagrama:

  • Ánodo (+) del LED (patilla larga) → Resistor 220Ω → Pin D18
  • Cátodo (-) del LED (patilla corta/lado plano) → Pin GND
⚠️ Importante: Siempre usa un resistor (220Ω o 330Ω) entre el LED y el ESP32 para evitar dañar el LED o el pin del microcontrolador. El resistor limita la corriente que pasa por el LED.
4 Escribir el Código

Copia y pega este código en el editor de Wokwi:

// Ejercicio 1: LED Parpadeante
// IF0112 - Complementaria II (IoT)

// Pin donde conectamos el LED
const int ledPin = 18;  // D18 en el ESP32

void setup() {
  // Configurar el pin del LED como SALIDA
  pinMode(ledPin, OUTPUT);

  // Inicializar el monitor serial (para ver mensajes)
  Serial.begin(115200);
  Serial.println("Ejercicio 1: LED Parpadeante iniciado");
}

void loop() {
  // Encender el LED
  digitalWrite(ledPin, HIGH);
  Serial.println("LED encendido 💡");

  // Esperar 1 segundo (1000 milisegundos)
  delay(1000);

  // Apagar el LED
  digitalWrite(ledPin, LOW);
  Serial.println("LED apagado");

  // Esperar 1 segundo
  delay(1000);
}
5 Ejecutar la Simulación

Haz clic en el botón ▶ Run Simulation (o presiona F8) en la parte superior derecha.

✅ ¡Si funciona! Verás el LED parpadeando cada 1 segundo (1 segundo encendido, 1 segundo apagado).
6 Ver el Monitor Serial

Abre el Monitor Serial haciendo clic en el botón Serial Monitor en la parte inferior. Verás los mensajes que el programa envía:

📖 Explicación del Código

Estructura Básica

Todo programa Arduino tiene dos funciones obligatorias:

  • setup(): Se ejecuta UNA vez al iniciar. Aquí configuramos los pines y inicializamos componentes.
  • loop(): Se ejecuta repetidamente en un ciclo infinito. Aquí va la lógica principal.

Funciones Usadas

Función Descripción
pinMode(pin, modo) Configura un pin como ENTRADA o SALIDA
digitalWrite(pin, valor) Escribe HIGH (5V/3.3V) o LOW (0V) en un pin
delay(milisegundos) Pausa el programa por X milisegundos
Serial.begin(baudios) Inicia comunicación serial a X baudios
Serial.print(valor) Envía texto al monitor serial

Constantes

const int ledPin = 18; define una constante para el pin. Usar constantes hace el código más legible y fácil de modificar.

🏆 Retos Adicionales

Una vez que funcione el código básico, intenta estos retos:

  1. Cambiar la velocidad: Modifica el delay() para que el LED parpadee más rápido (500 ms) o más lento (2000 ms).
  2. Diferentes tiempos: Haz que el LED esté encendido 2 segundos y apagado solo 0.5 segundos.
  3. Mensaje personalizado: Cambia los mensajes en el Serial Monitor por tus propios textos.
  4. Múltiples LEDs: Agrega otro LED en el pin D19 y haz que parpadeen alternadamente.

✅ Solución del Reto 4 (LEDs Alternantes)

Si intentaste el reto 4 y quieres verificar tu solución, aquí está el código:

// Reto: LEDs Alternantes
const int led1Pin = 18;
const int led2Pin = 19;

void setup() {
  pinMode(led1Pin, OUTPUT);
  pinMode(led2Pin, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  // LED 1 encendido, LED 2 apagado
  digitalWrite(led1Pin, HIGH);
  digitalWrite(led2Pin, LOW);
  Serial.println("LED1 ON, LED2 OFF");
  delay(500);

  // LED 1 apagado, LED 2 encendido
  digitalWrite(led1Pin, LOW);
  digitalWrite(led2Pin, HIGH);
  Serial.println("LED1 OFF, LED2 ON");
  delay(500);
}

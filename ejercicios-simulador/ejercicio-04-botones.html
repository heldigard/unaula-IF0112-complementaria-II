🔘 Ejercicio 4: Botón Controla LED

⏱️ 30 min | 📦 1 LED + 1 Botón | 🟠 Medio

🎯 Objetivo

Aprender a usar entradas digitales (botones) para controlar salidas. El LED solo se encenderá cuando presiones el botón.

📋 Diagrama de Conexión

Pasos de Conexión

1 Circuito del LED:
  • Conecta el ánodo (+) del LED (patilla larga) a un extremo del resistor de 220Ω
  • El otro extremo del resistor va al pin D18 del ESP32
  • El cátodo (−) del LED (patilla corta, lado plano) va a GND
2 Circuito del Botón:
  • El botón tiene 4 terminales organizadas en 2 filas: .l (LEFT) y .r (RIGHT)
  • Las terminales del mismo lado están conectadas internamente
  • Conecta 1.r (fila derecha, terminal superior) al pin D15
  • Conecta 1.l (fila izquierda, terminal superior) a 3.3V
  • En el código usamos INPUT_PULLUP, por lo que NO necesitas resistor externo
⚠️ Importante: El ESP32 activa una resistencia pull-up interna con INPUT_PULLUP. Esto significa que cuando el botón NO está presionado, el pin lee HIGH (3.3V). Cuando presionas el botón, conecta a GND y lee LOW.

📋 Código

// Ejercicio 4: Botón controla LED
const int ledPin = 18;
const int botonPin = 15;

int estadoBoton = HIGH;  // HIGH = no presionado (pull-up)
int ultimoEstadoBoton = HIGH;
int estadoLed = LOW;

unsigned long ultimoDebounce = 0;
unsigned long delayDebounce = 50;

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(botonPin, INPUT_PULLUP);  // Resistencia pull-up interna
  digitalWrite(ledPin, estadoLed);

  Serial.begin(115200);
  Serial.println("=== Ejercicio 4: Botón Controla LED ===");
  Serial.println("Presiona el botón para encender/apagar el LED");
}

void loop() {
  int lectura = digitalRead(botonPin);

  // Detectar cambio de estado con debounce
  if (lectura != ultimoEstadoBoton) {
    ultimoDebounce = millis();
  }

  if ((millis() - ultimoDebounce) > delayDebounce) {
    if (lectura != estadoBoton) {
      estadoBoton = lectura;

      if (estadoBoton == LOW) {  // LOW = presionado (pull-up)
        estadoLed = !estadoLed;
        digitalWrite(ledPin, estadoLed);

        Serial.print("Botón presionado. LED ahora: ");
        Serial.println(estadoLed ? "ENCENDIDO" : "APAGADO");
      }
    }
  }

  ultimoEstadoBoton = lectura;
}

🔍 Conceptos Importantes

INPUT_PULLUP

El ESP32 tiene resistencias pull-up internas. INPUT_PULLUP activa esta resistencia:

  • BOTÓN NO PRESIONADO: Pin lee HIGH (3.3V)
  • BOTÓN PRESIONADO: Pin lee LOW (0V, conectado a GND)

Debounce (Antirrebote)

Los botones "rebotan" cuando se presionan, enviando múltiples señales rápidas. El código usa un delay de 50ms para filtrar estos rebotes.

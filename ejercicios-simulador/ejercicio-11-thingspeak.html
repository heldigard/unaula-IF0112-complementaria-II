📊 Ejercicio 11: ThingSpeak - Envío de Datos a la Nube

⏱️ 45 min | 📶 ESP32 + Sensor DHT22 | 🟠 Medio

🎯 Objetivo

Crear un sistema IoT que envía datos de temperatura y humedad a ThingSpeak, una plataforma gratuita de monitoreo IoT.

💡 Concepto: ThingSpeak es una plataforma de análisis y visualización de datos. Es ideal para proyectos IoT simples, experimentos y prototipos.

📋 Requisitos Previos

  • ESP32 con sensor DHT22 conectado
  • Cuenta de ThingSpeak gratuita: https://thingspeak.com/signup
  • Write API Key de tu canal (se crea al hacer signup)
⚠️ CONFIGURACIÓN OBLIGATORIA ANTES DE EJECUTAR:

El código tiene 3 placeholders que DEBES reemplazar:

  1. TU_RED_WIFI → Nombre de tu red WiFi
  2. TU_CONTRASEÑA → Contraseña de tu WiFi
  3. TU_WRITE_API_KEY → Tu API Key de ThingSpeak

El programa se detendrá si no configuras estos valores.

🛠️ Paso 1: Crear Canal en ThingSpeak

  1. Regístrate en https://thingspeak.com/signup
  2. Ve a Channels → My Channels
  3. Crea un nuevo canal (Create New Channel)
  4. Nombra el canal (ej: "Mi Laboratorio IoT")
  5. Agrega campos:
    • Field 1: Temperatura (°C)
    • Field 2: Humedad (%)
  6. Guarda el canal
  7. Copia tu Write API Key (en la pestaña API Keys)
⚠️ Importante: Reemplaza TU_WRITE_API_KEY con tu API Key real. Esta es la única parte que debes cambiar para que funcione con tu cuenta.

📋 Código

#include <WiFi.h>
#include <DHT.h>
#include <HTTPClient.h>

// Credenciales WiFi
const char* ssid = "TU_RED_WIFI";
const char* password = "TU_CONTRASENA";

// Configuración ThingSpeak
const char* thingSpeakChannel = "TU_CHANEL_ID";
const char* writeAPIKey = "TU_WRITE_API_KEY";

// Configuración DHT22
#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);

  // Iniciar DHT22
  dht.begin();
  delay(2000);

  Serial.println("=== Iniciando IoT con ThingSpeak ===");

  // Conectar WiFi
  WiFi.begin(ssid, password);
  Serial.print("Conectando WiFi");

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\n✅ WiFi Conectado!");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  // ⚠️ VALIDACIÓN DE SEGURIDAD: Verificar que se reemplazaron los placeholders
  if (String(ssid) == "TU_RED_WIFI" || String(password) == "TU_CONTRASENA") {
    Serial.println("❌ ERROR: Debes configurar tu WiFi antes de ejecutar");
    Serial.println("   Reemplaza TU_RED_WIFI y TU_CONTRASENA con tus datos reales");
    while(true);  // Detener ejecución
  }
  
  if (String(writeAPIKey) == "TU_WRITE_API_KEY") {
    Serial.println("❌ ERROR: Debes configurar tu API Key de ThingSpeak");
    Serial.println("   Ve a https://thingspeak.com y crea un canal");
    Serial.println("   Copia tu Write API Key en el código");
    while(true);  // Detener ejecución
  }

  // Verificar que hay conexión WiFi
  if (WiFi.status() == WL_CONNECTED) {
    // Leer datos del sensor
    float temperatura = dht.readTemperature();
    float humedad = dht.readHumidity();

    // Verificar si lectura es válida
    if (isnan(temperatura) || isnan(humedad)) {
      Serial.println("❌ Error al leer DHT22");
      return;
    }

    Serial.println("=== Datos Leídos ===");
    Serial.print("Temperatura: ");
    Serial.print(temperatura);
    Serial.print(" °C | Humedad: ");
    Serial.print(humedad);
    Serial.println(" %");

    // Crear URL para enviar datos a ThingSpeak
    String url = "http://api.thingspeak.com/update?api_key=";
    url += writeAPIKey;
    url += "&field1=";
    url += String(temperatura);
    url += "&field2=";
    url += String(humedad);

    Serial.print("Enviando a ThingSpeak: ");
    Serial.println(url);

    // Enviar datos
    HTTPClient http;
    http.begin(url);

    int httpResponseCode = http.GET();

    if (httpResponseCode > 0) {
      Serial.print("✅ Datos enviados. Response: ");
      Serial.println(httpResponseCode);

      if (httpResponseCode == 200) {
        Serial.println("✅ Recepción confirmada por ThingSpeak");
      }
    } else {
      Serial.print("❌ Error: ");
      Serial.println(httpResponseCode);
    }

    http.end();

    // Esperar 15 minutos para ThingSpeak (limitación gratuita)
    // ThingSpeak permite máximo 3 envíos por minuto
    Serial.println("\n⏳ Esperando 15 minutos...");
    delay(900000);  // 15 minutos = 900000 ms
  } else {
    Serial.println("❌ WiFi no conectado. Reconectando...");
    WiFi.reconnect();
    delay(5000);
  }
}

🔧 Cómo Conectar el Hardware

💡 Conexiones del DHT22:
  • Pin 1 (VCC): Conecta a 3.3V del ESP32
  • Pin 2 (Data): Conecta a D4 (GPIO 4) - aquí se transmiten los datos
  • Pin 3 (NC): No conectar (Not Connected)
  • Pin 4 (GND): Conecta a GND del ESP32
🔧 Tip: El DHT22 tiene un orden específico de pines. Si los conectas al revés, el sensor no funcionará y podría dañarse. Observa la orientación: el pin 1 (VCC) está del lado izquierdo cuando miras el sensor de frente con la rejilla hacia arriba.

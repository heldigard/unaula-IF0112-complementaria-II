⚡ Primeros Pasos Recomendados

  1. Lee la Guía de Compra → Entiende qué necesitas y cuánto cuesta
  2. Compra el kit → Ve a JNC o compra online (recomendado: compra grupal)
  3. Instala Arduino IDE → Sigue la guía de instalación paso a paso
  4. Prueba tu kit → Sube el ejemplo Blink para verificar que todo funciona
  5. Explora los laboratorios → Familiarízate con las actividades del curso

💡 Tip Importante: No esperes a tener todo el kit para empezar. Puedes practicar con el simulador Wokwi mientras llegan los componentes.

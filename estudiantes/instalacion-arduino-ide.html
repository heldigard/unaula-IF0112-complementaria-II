Guía de Instalación Arduino IDE + ESP32

IF0112 - Complementaria II | Paso a Paso

🏠 Inicio 📋 Guía Rápida 🛒 Guía de Compra 🔬 Laboratorios

🎯 Objetivo: Instalar y configurar Arduino IDE en tu computadora para programar el ESP32.

⏱️ Tiempo estimado: 20-30 minutos | Dificultad: Principiante

📋 Requisitos Previos

Hardware

  • Computadora con Windows 10/11, macOS, o Linux
  • 4GB de RAM mínimo (8GB recomendado)
  • 500MB de espacio libre

Software

  • Conexión a internet
  • Permisos de administrador

🪟 Paso 1: Instalar Arduino IDE (10 min)

Para Windows 10/11

1. Descargar Arduino IDE

  • Ir a: https://www.arduino.cc/en/software
  • Click en "Download" para Windows
  • Elegir "Win 10 or later" (64 bits)

2. Ejecutar instalador

  • Abrir archivo descargado (arduino-ide_xxx.exe)
  • Click "Sí" cuando pida permisos
  • Aceptar términos de licencia

3. Opciones recomendadas

  • ☑️ Crear acceso directo en escritorio
  • ☑️ Asociar archivos .ino
  • ☑️ Resetear configuraciones previas (si pregunta)

4. Completar instalación

  • Esperar a que termine
  • Click "Close" al finalizar

Para macOS

1. Descargar Arduino IDE

  • Ir a: https://www.arduino.cc/en/software
  • Click en "Download" para macOS
  • Descargar archivo .dmg

2. Instalar

  • Abrir archivo .dmg descargado
  • Arrastrar "Arduino IDE" a "Aplicaciones"
  • Esperar copia

3. Abrir primera vez

  • Click derecho > Abrir
  • Aceptar advertencia de seguridad

Para Linux (Ubuntu/Debian)

# Descargar y agregar clave GPG
wget https://www.arduino.cc/software/signing-keys/arduino-keyring.asc
sudo gpg --dearmor -o /usr/share/keyrings/arduino-keyring.gpg arduino-keyring.asc

# Agregar repositorio
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/arduino-keyring.gpg] https://downloads.arduino.cc/arduino-ide stable main" | sudo tee /etc/apt/sources.list.d/arduino-ide.list

# Actualizar e instalar
sudo apt update
sudo apt install arduino-ide

🔌 Paso 2: Instalar Drivers ESP32 (10 min)

El ESP32 necesita drivers USB para comunicarse con tu computadora.

Identificar tu ESP32

Conecta el ESP32 y verifica en el Administrador de Dispositivos:

  • Windows: Buscar "Administrador de dispositivos"
  • macOS: Acerca de este Mac > Informe del sistema
  • Linux: lsusb

Driver CP2102 (Común)

Necesario si: Tu ESP32 tiene chip CP2102

Windows:

  1. Descargar: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
  2. Ejecutar instalador
  3. Reiniciar computadora

macOS:

  1. Descargar versión para macOS
  2. Abrir paquete .pkg
  3. Seguir instrucciones

Linux:

sudo apt install linux-modules-extra-raspi-generic

Driver CH340 (Alternativa)

Necesario si: Tu ESP32 tiene chip CH340

Windows:

  1. Descargar: http://www.wch.cn/download/CH341SER_EXE.html
  2. Ejecutar y reiniciar

macOS:

  1. Permitir apps de desarrolladores identificados
  2. Descargar e instalar driver
  3. Reiniciar

⚙️ Paso 3: Configurar Arduino IDE para ESP32 (10 min)

3.1 Abrir Arduino IDE

  • Doble click en ícono de Arduino IDE
  • Esperar a que cargue completamente

3.2 Agregar URL de ESP32

1. Abrir Preferencias

  • Windows/Linux: Ctrl + ,
  • macOS: Arduino IDE > Preferences

2. Encontrar "Additional Boards Manager URLs"

Campo: "Gestor de tarjetas adicionales"

3. Agregar esta URL:

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

4. Click OK

3.3 Instalar Paquete ESP32

1. Abre el Gestor de Tarjetas

Herramientas > Placa > Gestor de tarjetas...

2. Buscar "ESP32"

  • En el campo de búsqueda escribir "esp32"
  • Esperar resultados

3. Instalar

  • Buscar "esp32 by Espressif Systems"
  • Click en "Instalar"
  • Esperar (puede tardar 5-10 minutos)
  • Click "Cerrar" cuando termine

✅ Paso 4: Verificar Instalación

4.1 Seleccionar Placa

  1. Herramientas > Placa > esp32
  2. Seleccionar "ESP32 Dev Module"

4.2 Conectar ESP32

  1. Conectar ESP32 con cable USB
  2. Herramientas > Puerto
  3. Seleccionar el puerto que aparece:

Windows: COM3, COM4, COM5 (el número puede variar)

macOS: /dev/cu.usbserial-... o /dev/cu.SLAB_USBtoUART...

Linux: /dev/ttyUSB0 o /dev/ttyUSB1

4.3 Probar con Ejemplo Blink

  1. Archivos > Ejemplos > 01.Basics > Blink
  2. Modificar para ESP32: Cambiar LED_BUILTIN por 2
  3. Click en "Subir" (flecha →)
  4. Si falla: Mantener presionado botón "BOOT" en ESP32 mientras sube

4.4 Verificar

✅ Éxito:

  • Mensaje "Subido exitosamente"
  • LED azul en ESP32 parpadeando

❌ Error: Ver sección de Troubleshooting

🚨 Troubleshooting

Problema: "No se encuentra el puerto"

Solución:

  1. Verificar cable USB (algunos solo cargan, no transmiten)
  2. Reinstalar drivers
  3. Probar otro puerto USB
  4. Probar otra computadora (para descartar problema de ESP32)

Problema: "Failed to connect"

Solución:

  1. Mantener presionado botón "BOOT" al subir
  2. Presionar botón "RESET" antes de subir
  3. Verificar puerto correcto seleccionado
  4. Cambiar cable USB

Problema: "Permission denied" (Linux)

# Agregar usuario al grupo dialout
sudo usermod -aG dialout $USER

# Cerrar sesión y volver a entrar

Problema: Arduino IDE no abre (macOS)

  1. Click derecho sobre Arduino IDE
  2. Mantener presionada tecla Option
  3. Click "Abrir"
  4. Aceptar en advertencia

✅ Checklist Final

Antes del primer laboratorio:

  • Arduino IDE instalado y abre correctamente
  • Drivers de ESP32 instalados
  • Puerto COM detectado al conectar ESP32
  • Placa "ESP32 Dev Module" seleccionada
  • Ejemplo Blink subido exitosamente
  • LED parpadeando en ESP32

¡Listo para programar! 🚀

Plataformas IoT Cloud Gratuitas

Opciones recomendadas para el curso IF0112 - Todas gratuitas para educación

🏠 Inicio Clases 📋 Evaluaciones 🔬 Laboratorios

1. Ubidots STEM ⭐ RECOMENDADA

URL: https://stem.ubidots.com

Características:

  • ✅ Gratis para siempre (plan STEM)
  • ✅ 3 dispositivos gratuitos
  • ✅ 4,000 datos/hora por dispositivo
  • ✅ Dashboards profesionales y widgets personalizables
  • ✅ Alertas por correo electrónico
  • ✅ API HTTP y MQTT
  • ✅ Excelente para educación e investigación

Registro:

  1. Usar correo institucional (@unaula.edu.co)
  2. Seleccionar "Student or Teacher" al registrarse
  3. Verificar correo

URL de la API:

http://things.ubidots.com/api/v1.6/devices/esp32/?token=TU_TOKEN

2. ThingSpeak (MathWorks)

URL: https://thingspeak.com

Características:

  • ✅ Gratuito con limitaciones
  • ✅ 3 millones de mensajes/año
  • ✅ Hasta 4 canales
  • ✅ Máximo 8 campos por canal
  • ✅ Actualización máxima cada 15 segundos
  • ✅ Integración con MATLAB

Limitaciones del plan gratuito:

  • Rate limit: 1 mensaje cada 15 segundos
  • No permite mensajes privados ilimitados
  • Análisis MATLAB básico

URL de la API:

http://api.thingspeak.com/update?api_key=TU_KEY&field1=valor1&field2=valor2

3. Arduino IoT Cloud

URL: https://cloud.arduino.cc

Características:

  • ✅ Gratis para uso personal
  • ✅ Integración nativa con ESP32
  • ✅ Dashboard simple y elegante
  • ✅ OTA (Over-The-Air) updates
  • ✅ 25 días de retención de datos

Limitaciones:

  • Requiere autenticación Arduino
  • Retención de datos limitada
  • Menos flexible que otras opciones

4. Blynk

URL: https://blynk.io

Características:

  • ✅ Plan gratuito disponible
  • ✅ Dashboard móvil y web
  • ✅ App para Android/iOS
  • ✅ Notificaciones push

Limitaciones del plan gratuito:

  • 10 dispositivos
  • 5 usuarios
  • Datos se borran después de 30 días de inactividad

5. ThingsBoard (Open Source)

URL: https://thingsboard.io

Características:

  • ✅ 100% open source
  • ✅ Cloud gratuito disponible
  • ✅ Auto-hospedaje posible
  • ✅ Dashboards avanzados
  • ✅ Soporte MQTT, HTTP, CoAP

Opciones:

  • Live Demo: https://demo.thingsboard.io (gratis con límites)
  • Instalación local: Descargar y ejecutar en tu computadora

💡 Recomendación para el Curso

Para estudiantes principiantes:

→ Usar Ubidots STEM (más estable y gratuito permanente)

Para integración MATLAB:

→ Usar ThingSpeak (si se necesita análisis avanzado)

Para auto-hospedaje:

→ Usar ThingsBoard (si quieren aprender administración de servidores)

📝 Notas Importantes

  1. Todas las opciones listadas son gratuitas para uso educativo/personal
  2. Ubidots STEM es la opción más estable y permanente
  3. ThingSpeak funciona bien pero tiene rate limits estrictos
  4. Se puede cambiar de plataforma en cualquier momento (cambiar solo la URL y token en el código)
  5. El protocolo HTTP GET funciona igual en todas las plataformas

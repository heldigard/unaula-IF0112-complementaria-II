Proyecto Integrador: Sistema de Monitoreo Ambiental IoT

IF0112 - Complementaria II (IoT) 2026-I | Proyecto Progresivo

🏠 Inicio 📋 Evaluaciones 👥 Estudiantes 🔬 Laboratorios

🎯 Objetivo: Construir un sistema IoT completo que monitoree variables ambientales (temperatura, humedad, intensidad lumínica) y transmita los datos a una plataforma en la nube para su visualización.

🔄 Flujo del Proyecto (Incremental)

Fase 1: E1 - Investigación (15%)

Entregable: Documento de arquitectura técnica

  • Define la estructura de 4 capas del sistema
  • Especifica hardware: ESP32, DHT22, LDR
  • Selecciona pines GPIO específicos
  • Base conceptual para todo el proyecto

Próximo paso: E2 - Prototipo (usa las especificaciones de E1)

Fase 2: E2 - Prototipo (15%)

Entregable: Circuito físico funcionando

  • Montaje físico según arquitectura de E1
  • Conexión de sensores a pines especificados
  • Lectura local de datos (Monitor Serial)
  • Prerrequisito: Haber aprobado E1

Próximo paso: E3 - Software (agrega WiFi al circuito de E2)

Fase 3: E3 - Software (20%)

Entregable: Código con conectividad Cloud

  • Hereda circuito de E2 (sin modificar hardware)
  • Agrega conexión WiFi (STA)
  • Envío de datos a ThingSpeak cada 20 segundos
  • Dashboard en la nube visible
  • Prerrequisito: Circuito de E2 funcionando

Próximo paso: E4 - Informe (agrega lógica inteligente al código de E3)

Fase 4: E4 - Lógica de Gestión (15%)

Entregable: Sistema con estados y alertas

  • Hereda código de E3 (mismo circuito)
  • Agrega máquina de estados (NORMAL, ALERTA_TEMP, ALERTA_LUZ)
  • LEDs indicadores de estado
  • Histeresis en umbrales (30°C/28°C)
  • Prerrequisito: Código de E3 con WiFi funcionando

Próximo paso: E5 - Normativa (documenta el producto funcionando)

Fase 5: E5 - Normativa (15%)

Entregable: Documentación legal y técnica

  • Documenta producto funcionando de E4
  • Cumplimiento RETIE
  • Ley 1581 - Protección de datos (ARCO)
  • Ficha técnica del dispositivo
  • Prerrequisito: Producto SMAI funcionando de E4

Próximo paso: E6 - Proyecto Final (integra todo)

Fase 6: E6 - Proyecto Final (20%) 🎯

Entregable: Producto terminado y encapsulado

  • Integra todos los entregables E1-E5
  • Dispositivo encapsulado (caja/protección)
  • Funcionamiento autónomo completo
  • Sustentación tipo pitch (10-15 min)
  • Demo en vivo del sistema
  • Requiere: Todos los entregables E1-E5 completos

💡 Consejos para el Proyecto

📌 Mantén el mismo circuito todo el semestre

Regla de oro: Desde E2 hasta E6 usas el MISMO circuito físico. Solo vas agregando código y mejorando el firmware.

Beneficios:

  • ✅ Ahorras tiempo (no rehaces conexiones)
  • ✅ Reduce errores de conexión
  • ✅ Ves progreso real clase a clase
  • ✅ Producto final robusto y probado

⚠️ Errores Comunes a Evitar

  • ❌ Desarmar el circuito entre evaluaciones
  • ❌ Cambiar pines GPIO en cada entrega
  • ❌ Empezar desde cero en cada evaluación
  • ❌ Dejar todo para la última semana
  • ❌ No documentar cambios en el código

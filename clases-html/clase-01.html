¿Qué es Internet de las Cosas?

IoT es la interconexión de objetos físicos cotidianos con Internet, permitiéndoles enviar y recibir datos sin intervención humana directa.

Ejemplo cotidiano: Un smartwatch que mide tu ritmo cardíaco, cuenta pasos y te notifica si detecta una frecuencia cardíaca irregular, todo automáticamente.

El Valor de IoT

  • Automatización: Procesos que ocurren sin intervención humana
  • Optimización: Uso eficiente de recursos (energía, agua, tiempo)
  • Nuevos modelos de negocio: Servicios basados en datos

Componentes de un Sistema IoT

Un sistema IoT requiere 4 componentes fundamentales:

Componente Función Ejemplo Cotidiano
📡 Sensores Capturan datos del mundo físico Termostato que mide temperatura
📶 Conectividad Transmiten datos a la nube WiFi que envía datos al servidor
🧠 Procesamiento Analizan y toman decisiones IA que ajusta la temperatura
⚡ Actuadores Ejecutan acciones físicas Aire acondicionado se enciende
💡 Insight: El valor de IoT surge cuando estos 4 componentes trabajan juntos en un ciclo: Sensor → Conectividad → Procesamiento → Actuador

Evolución de Internet

Las 4 Eras de la Conectividad Digital

Era Período Hito Tecnológico Característica
ARPANET 1969 Primer mensaje entre 4 universidades Nace Internet (red de computadoras)
WWW 1991 HTML y navegadores Internet accesible para todos
Web 2.0 2004-2007 Facebook, iPhone Todos producen contenido
IoT 2015+ AWS IoT, sensores masivos Todo inteligente conectado
Colombia en la historia: En 1991, Colombia fue uno de los primeros 5 países latinoamericanos en conectarse a Internet, mediante Uniandes con una conexión de 64 Kbps.

Drivers Tecnológicos de IoT

El crecimiento explosivo de IoT se debe a 5 factores convergentes:

Driver Evolución Impacto
💰 Hardware Sensores de $5 → $0.50 Barato conectar cualquier cosa
📡 Conectividad WiFi, 4G, LoRa, NB-IoT Cobertura universal
☁️ Cloud AWS, Azure, GCP IoT Procesamiento accesible
🧠 IA Machine Learning accesible Decisiones automáticas
🔋 Baterías 1 mes → 10 años de duración Sensores sin cables
El ESP32: Un microcontrolador con WiFi y Bluetooth por solo $3-5, que hace posible IoT masivo.

Internet de Todo (IoE)

IoE = IoT + Personas + Procesos + Datos

Mientras IoT se enfoca en conectar dispositivos, IoE representa el ecosistema completo donde personas, procesos, datos y cosas se interconectan para crear valor de negocio.

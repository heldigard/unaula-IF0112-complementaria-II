Visualización de Datos

En E5 debes mostrar los datos de tu API de forma gráfica. La opción más sencilla es una página HTML con JavaScript que consulte tu API local. También puedes usar Grafana si ya lo conoces.

Opción 1: HTML + JavaScript

  • Solo necesitas un archivo index.html y un navegador.
  • Usa fetch() para llamar GET /datos/latest cada 5 segundos.
  • Muestra temperatura, humedad y luz en tarjetas o gráficas simples.
  • Recuerda habilitar CORS en FastAPI.

Opción 2: Grafana (avanzado)

  • Conecta Grafana directamente a SQLite con un plugin.
  • Crea paneles con gráficas de líneas del historial.
  • Requiere algo más de configuración inicial.
  • Se ve muy profesional en la sustentación.

Ejemplo: Dashboard HTML Simple

Este código consulta tu API local y muestra el último dato recibido:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Monitor SMAI</title>
  <style>
    body { font-family: sans-serif; text-align: center; background: #f0f9ff; }
    .card { background: white; padding: 20px; margin: 10px auto; width: 200px; border-radius: 10px; }
    .temp { color: #ef4444; font-size: 2rem; }
    .hum  { color: #3b82f6; font-size: 2rem; }
    .luz  { color: #f59e0b; font-size: 2rem; }
  </style>
</head>
<body>
  <h1>Monitor Ambiental</h1>
  <div class="card">Temperatura<br><span class="temp" id="t">--</span> °C</div>
  <div class="card">Humedad<br><span class="hum" id="h">--</span> %</div>
  <div class="card">Luz<br><span class="luz" id="l">--</span> %</div>

  <script>
    async function actualizar() {
      const res = await fetch('http://192.168.1.X:8000/datos/latest');
      const json = await res.json();
      document.getElementById('t').textContent = json.dato.temperatura;
      document.getElementById('h').textContent = json.dato.humedad;
      document.getElementById('l').textContent = json.dato.luz;
    }
    setInterval(actualizar, 5000);
    actualizar();
  </script>
</body>
</html>

Nota: Reemplaza 192.168.1.X por la IP local de tu PC donde corre FastAPI.

Taller: Integración Completa

Durante esta sesión cada grupo debe lograr que todo funcione junto. El profesor estará recorriendo los puestos para ayudar.

Checklist del Flujo Completo

  • ☐ El ESP32 enciende y se conecta a WiFi en menos de 30 segundos
  • ☐ La API FastAPI está corriendo en la laptop (uvicorn main:app --host 0.0.0.0)
  • ☐ Swagger UI responde en http://localhost:8000/docs
  • ☐ El ESP32 envía JSON por HTTP POST y recibe respuesta 200
  • ☐ La base de datos SQLite tiene datos reales del ESP32
  • ☐ El dashboard HTML muestra valores actualizados
  • ☐ CORS está habilitado en la API (si usas visualización web)

Comandos útiles para el taller

# Levantar API en red local (Windows)
uvicorn main:app --host 0.0.0.0 --port 8000

# Ver IP local de tu PC
ipconfig

# Probar API desde otra laptop
curl http://192.168.1.X:8000/datos/latest

Caso SIATA Medellín

Medellín opera uno de los sistemas IoT urbanos más avanzados de Latinoamérica. SIATA monitorea +100 estaciones en el Valle de Aburrá para prevenir desastres por inundaciones.

Arquitectura SIATA

  • Edge: Pluviómetros, higrómetros, RADAR meteorológico, cámaras
  • Comunicación: Fibra óptica + radiofrecuencia propia
  • Cloud: Bases de datos históricas, modelos ML, dashboards
  • Alertas: SMS, sirenas, app móvil (menos de 5 min)

Lecciones para su proyecto

  • Multi-sensor: Combinar temperatura + humedad + luz da más contexto
  • Edge processing: La máquina de estados en el ESP32 es un mini-SIATA
  • Visualización: Un dashboard claro vale más que mil registros crudos
  • Fiabilidad: Red propia y redundancia = sistema crítico

Diferencias clave

SIATA: Sistema crítico, red propia, 24/7, presupuesto millonario.
Su proyecto: Prototipo educativo, WiFi público, alcance limitado.
Meta: Aplicar los principios de SIATA a escala de su SMAI.

🌧️ SIATA: Sistema de Alerta Temprana de Medellín

📝 Contexto

Medellín está en una zona de alta vulnerabilidad a inundaciones. SIATA es un sistema IoT que monitorea +100 estaciones en tiempo real para prevenir desastres.

Datos del Sistema

  • Estaciones: +100 sensores distribuidos en el Valle de Aburrá
  • Datos: 1.5 millones de registros diarios
  • Tiempo real: Alertas en menos de 5 minutos
  • Ahorro: USD 10M/año en prevención de daños

🏗️ Arquitectura SIATA

🔧 CAPA 1: Sensores (Edge)

  • Pluviómetros: Medición de lluvia en tiempo real
  • Higrómetros: Humedad del suelo
  • RADAR meteorológico: Precipitación a 120km
  • Cámaras: Monitoreo visual de quebradas

⚡ CAPA 2: Comunicación

  • Red propia: Fibra óptica + radiofrecuencia
  • Protocolos: MQTT para alertas, HTTP para datos históricos
  • Gateways: Recolectan datos de múltiples sensores

☁️ CAPA 3: Cloud + Analytics

  • Almacenamiento: Bases de datos históricas
  • Modelos ML: Predicción de inundaciones
  • Dashboards: Centros de comando, app móvil
  • Alertas: SMS, sirenas, notificaciones push

💡 Lecciones para su Proyecto

✅ Lo que SIATA hace bien

  • Red propia: No depende de internet público
  • Multi-sensor: Diferentes tipos de datos
  • Edge processing: Decisiones locales rápidas
  • ML predictivo: Anticipa, no solo reacciona
  • Multi-canal: Alertas por SMS, app, sirenas

🎯 Aplicable a su proyecto

  • Diversidad de sensores: Temperatura + humedad + luz
  • Edge: Procesamiento en ESP32 (promedios)
  • Cloud: ThingSpeak para almacenamiento
  • Alertas: Umbrales configurables
  • Visualización: Dashboard Grafana

⚠️ Diferencias Clave

  • SIATA: Sistema crítico, redundancia, red propia, 24/7
  • Su proyecto: Prototipo educativo, WiFi público, alcance limitado

Meta: Aplicar los principios de SIATA a escala de su proyecto.

Ejemplo de Respuesta

Estándares: IEEE 802.11 (WiFi), MQTT para alertas, HTTP/REST para datos.

Seguridad: Encriptación, autenticación, red privada.

Lección aplicable: Usar múltiples sensores y visualización en dashboard.

Limitación aceptable: Depender de WiFi público (vs red propia).

📝 Resumen: SIATA

  • +100 estaciones monitoreando el Valle de Aburrá
  • Arquitectura 3 capas: Sensores → Comunicación → Cloud
  • Datos: 1.5M registros diarios, alertas <5 min
  • Lecciones clave: Multi-sensor, edge processing, ML predictivo
  • Aplicable: Principios de arquitectura y procesamiento

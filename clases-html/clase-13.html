Taller: Últimos Ajustes al Proyecto

Durante los primeros 30 minutos el profesor recorre los puestos ayudando a resolver problemas técnicos. Estos son los ajustes más comunes antes de E6:

🔧 Hardware

  • Verificar que el ESP32 enciende automáticamente al conectar USB
  • Revisar que no hay cables sueltos (usar amarras)
  • Encapsular el dispositivo en una caja o gabinete provisional
  • Probar LEDs de estado según la máquina de estados

💻 Software

  • Confirmar que la API arranca sin errores con uvicorn main:app
  • Verificar CORS habilitado para el dashboard web
  • Asegurar que la BD tiene datos históricos reales (no de prueba)
  • Comprobar que el dashboard actualiza sin recargar la página

Simulacro de Sustentación

Cada grupo tiene 3 minutos para presentar. El formato es el mismo que usarán en E6. El profesor y compañeros tomarán notas para dar feedback.

Estructura sugerida del pitch (3 min)

  1. Presentación del problema (30 s): Qué monitorean y por qué.
  2. Demo técnica en vivo (90 s): Encender ESP32, mostrar API, BD y dashboard.
  3. Explicación del flujo (30 s): Firmware → API → BD → Visualización.
  4. Cierre (30 s): Conclusión y qué aprendieron.

Preguntas tipo que pueden hacer en E6

  • ¿Por qué usaste millis() en vez de delay()?
  • ¿Cómo funciona la histéresis en tu máquina de estados?
  • ¿Qué endpoints tiene tu API y qué hace cada uno?
  • ¿Cuál es el schema de tu base de datos?
  • ¿Por qué habilitaste CORS y qué problema resuelve?
  • ¿Qué diferencia hay entre HTTP y MQTT en tu proyecto?

Tendencias del Futuro de IoT

Aunque el foco de hoy es la sustentación, es útil conocer hacia dónde evoluciona la industria. Estas tres tendencias resumen el futuro cercano:

📶 5G y Redes IoT

  • Latencia: De 30-50 ms (4G) a 1-5 ms (5G).
  • Densidad: Hasta 1 millón de dispositivos por km².
  • Impacto: Habilita vehículos autónomos, cirugía remota y fábricas inteligentes.

🤖 AIoT (IA + IoT)

  • Los dispositivos no solo recolectan datos, sino que toman decisiones.
  • Ejemplos: mantenimiento predictivo, optimización de tráfico, detección de anomalías.
  • Tu máquina de estados con histéresis es un primer paso hacia AIoT.

🔧 TinyML

  • Machine learning en microcontroladores como el ESP32.
  • Permite detectar patrones o anomalías sin depender de la nube.
  • Ejemplo: predecir condiciones críticas de temperatura localmente.

🎯 Aplicable a su proyecto

  • Edge processing: Tu máquina de estados ya decide localmente.
  • Visualización: Un dashboard claro vale más que mil registros crudos.
  • Escalabilidad: FastAPI + SQLite pueden crecer a servicios en la nube.

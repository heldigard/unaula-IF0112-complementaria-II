¿Qué es un Microcontrolador (MCU)?

Una computadora completa en un solo chip que integra CPU, memoria, puertos de entrada/salida y periféricos.

Sensores y Actuadores Comunes

🔍 ¿Digital vs Analógico?
Digital: Envía datos codificados (0s y 1s) por un protocolo. Más preciso, menos ruido.
Analógico: Varía un voltaje continuamente. Más simple, pero requiere calibración.

Sensores Digitales

Envían información codificada mediante protocolos. El microcontrolador recibe un valor numérico listo para usar.

💡 ¿Por qué DHT22 sobre DHT11?
El DHT22 tiene mejor precisión (±0.5°C vs ±2°C), mayor rango de temperatura (-40°C a 80°C), y responde más rápido a cambios. Para el proyecto SMAI donde necesitas detectar alertas de temperatura con precisión, el DHT22 es la mejor opción.

Sensores Analógicos

Varián su resistencia o voltaje de salida. Requieren el ADC del ESP32 para convertirlos a valores digitales.

SensorNombre completoMidePrincipio de funcionamientoUso típico
LDR Light Dependent Resistor
(Fotorresistencia)		 Luz ambiente Su resistencia disminuye con más luz. Se usa con un divisor de voltaje para leer el nivel de iluminación. SMAI: Detectar oscuridad para alertas, controlar luces automáticas
LM35 LM35 Precision Temperature Temperatura Genera 10mV por cada °C. Ejemplo: 25°C = 250mV de salida. Monitoreo de temperatura simple (alternativa analógica al DHT)
Potenciómetro Resistencia variable Posición rotatoria Un cursor móvil sobre una pista resistiva varía el voltaje de salida. Controles de volumen, brillo, ajustes manuales
🔧 Cómo leer un LDR:
El LDR se conecta en un divisor de voltaje con una resistencia fija (10KΩ típico):
3.3V → LDR → [Punto de medición] → Resistencia 10KΩ → GND
En el punto de medición, el ADC lee un valor entre 0 (sin luz) y 4095 (mucha luz).

Guía de Conexión: DHT22 + LDR al ESP32

🌡️ Sensor DHT22 (Temperatura + Humedad)

Pin DHT22 Conectar a Color cable
VCC (Pin 1) 3.3V del ESP32 🔴 Rojo
DATA (Pin 2) GPIO 4 del ESP32 🔵 Azul
GND (Pin 4) GND del ESP32 ⚫ Negro
⚠️ OBLIGATORIO: Resistencia 4.7KΩ - 10KΩ entre DATA y VCC
Sin ella, el sensor devuelve "NaN" o falla la lectura.

☀️ Sensor LDR (Luz)

Componente Conexión
LDR (patita 1) 3.3V del ESP32
LDR (patita 2) GPIO 34 + Resistencia 10KΩ
Resistencia 10KΩ Entre GPIO 34 y GND
📐 Divisor de voltaje:
3.3V → LDR → [GPIO34] → 10KΩ → GND
Más luz = mayor voltaje en GPIO34

💡 ¿Por qué GPIO 34 para el LDR?
El ESP32 tiene dos convertidores ADC: ADC1 (GPIO32-39) y ADC2 (GPIO0, 2, 4, 12-15, 25-27).
Cuando el WiFi está activo, ADC2 no puede usarse. Por eso usamos GPIO34 (ADC1_CH6) para el LDR.
El DHT22 usa protocolo digital 1-Wire, así que puede ir en cualquier GPIO (usamos GPIO4).

📚 Glosario de Términos de Hardware

Conceptos clave que debes conocer para trabajar con microcontroladores:

Término Significado Descripción
GPIO General Purpose Input/Output Pines de entrada/salida de propósito general
ADC Analog-to-Digital Converter Conversor de señal analógica a digital
PWM Pulse Width Modulation Modulación por ancho de pulso (control intensidad)
I2C Inter-Integrated Circuit Protocolo de comunicación entre circuitos integrados
SPI Serial Peripheral Interface Interfaz serie para periféricos (alta velocidad)
UART Universal Asynchronous Receiver-Transmitter Transmisor-receptor asíncrono universal
DAC Digital-to-Analog Converter Conversor de señal digital a analógica
SRAM Static Random Access Memory Memoria RAM estática (rápida, volátil)
Flash Flash Memory Memoria flash (almacena programa, no volátil)
💡 Nota importante: En el ESP32, los pines GPIO pueden configurarse como entrada o salida usando pinMode(). El ADC convierte voltajes (0-3.3V) en números digitales (0-4095 en ESP32).

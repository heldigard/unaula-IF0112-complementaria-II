Tiempo Actividad

3 min Flujo de datos: Explicar Firmware → API → BD → Visualización
3-5 min Preguntas: Defensa técnica del proyecto

Requisitos del SMAI Final

  • Hardware: ESP32 montado firmemente con sus sensores (DHT22 / LDR)
  • Encapsulado: El dispositivo no debe tener cables sueltos (usar caja, gabinete o soporte)
  • Conectividad: WiFi estable enviando datos a la API propia (FastAPI o MQTT)
  • API + BD: FastAPI local (o broker MQTT + subscriber) con base de datos SQLite/MySQL
  • Visualización: Dashboard web propio (HTML+JS), Grafana, o interfaz que consuma la API

Recuerda: E6 es la entrega final del proyecto, presentada con sustentación oral y demo en vivo. Puedes usar FastAPI + BD o MQTT + BD. ThingSpeak y Ubidots son opcionales, no requisito.

Consejos para la Sustentación

Preparación Técnica

  • Verificar que el ESP32 enciende automáticamente al conectar USB
  • Asegurar que los cables no se suelten al mover el dispositivo
  • Tener una fuente de alimentación externa (power bank o USB)
  • Probar el dashboard en modo incógnito del navegador
  • Confirmar que PC y ESP32 están en la misma red WiFi

Para la Sustentación Oral

  • Practicar la demo varias veces con un cronómetro
  • Preparar respuestas a preguntas técnicas típicas
  • Designar quién explica cada capa (firmware, API, BD, visualización)
  • Tener todo listo la noche anterior
  • Mostrar confianza y dominio del proyecto

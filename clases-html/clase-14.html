Requisitos del SMAI Final

  • Hardware: ESP32 montado firmemente con sus sensores (DHT22/LDR)
  • Encapsulado: El dispositivo no debe tener cables sueltos (usar caja/soporte)
  • Conectividad: WiFi estable reportando a ThingSpeak
  • Visualización: Dashboard profesional en Grafana

💡 Consejos para el Proyecto Final

🛠️ Preparación Técnica

  • Verificar el encapsulado y aislamiento
  • Asegurar que los cables no se suelten al mover el dispositivo
  • Tener una fuente de alimentación externa (USB)
  • Probar el dashboard en modo incógnito

🎤 Para la Sustentación

  • Practicar la demo varias veces
  • Preparar respuestas a preguntas típicas
  • Tener todo listo la noche anterior
  • Mostrar confianza y dominio del proyecto

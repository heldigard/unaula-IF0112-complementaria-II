Refuerzo: Dudas de API y BD

Preguntas frecuentes de la semana

  • ¿Cómo encuentro mi IP local? En Windows: abrir CMD y escribir ipconfig. Buscar "Dirección IPv4" en la red WiFi.
  • ¿Por qué el ESP32 no llega a la API? Verificar que PC y ESP32 estén en la misma red WiFi. El firewall de Windows puede bloquear el puerto 8000.
  • ¿Dónde queda la base de datos SQLite? En el archivo sensores.db dentro de la carpeta del proyecto. Se puede abrir con DB Browser for SQLite.
  • ¿Cómo instalo las dependencias? pip install -r requirements.txt en la carpeta del proyecto.

API Avanzada: Filtros y Paginación

Query Parameters

Permiten filtrar datos sin cambiar la URL base:

  • GET /datos?limit=10 → Solo 10 registros.
  • GET /datos?desde=2026-04-20 → Filtrar por fecha.
  • GET /datos?min_temp=25 → Solo temperaturas mayores a 25°C.

Paginación simple

Evita devolver miles de filas de golpe:

  • offset: Desde qué fila empezar.
  • limit: Cuántas filas traer.
  • Ejemplo: SELECT * FROM sensores LIMIT ? OFFSET ?

💻 Código de ejemplo: endpoint con filtros

@app.get("/datos")
def listar_datos(limit: int = 100, min_temp: float | None = None):
    conn = sqlite3.connect(DB_NAME)
    cursor = conn.cursor()
    sql = "SELECT * FROM sensores WHERE 1=1"
    params = []
    if min_temp is not None:
        sql += " AND temperatura >= ?"
        params.append(min_temp)
    sql += " ORDER BY timestamp DESC LIMIT ?"
    params.append(limit)
    cursor.execute(sql, params)
    filas = cursor.fetchall()
    conn.close()
    return {"datos": filas}

MQTT: Alternativa al HTTP POST

¿Cuándo usar MQTT?

  • Quieres desacoplar el ESP32 de la API.
  • Necesitas que varios dispositivos escuchen el mismo dato.
  • Prefieres no depender de que la API esté 100% online.
  • El broker almacena mensajes cuando el suscriptor está offline.

Arquitectura MQTT

  • Broker: Servidor central que recibe y redistribuye mensajes.
  • Topic: Canal donde se publican los datos (ej: unaula/if0112/sensores).
  • Publish: El ESP32 envía el JSON al topic.
  • Subscribe: Script Python recibe el JSON y lo guarda en SQLite.

Troubleshooting: Problemas Comunes

CORS bloqueado

Síntoma: El navegador rechaza peticiones desde tu dashboard HTML.

Solución: Instalar python-multipart y agregar middleware CORS en FastAPI:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

Firewall de Windows

Síntoma: El ESP32 no puede hacer POST a la IP de tu PC.

Solución: Permitir Python/uvicorn en el firewall, o desactivar temporalmente el firewall de red privada para probar.

IP local incorrecta

Síntoma: El ESP32 no conecta o devuelve error -1.

Solución: Verificar ipconfig y asegurar que la IP empiece por 192.168. (WiFi), no por 127.0.0.1.

La BD no crea la tabla

Síntoma: Error "no such table: sensores".

Solución: Asegurar que la función de inicialización de la BD se ejecute al iniciar la API, antes del primer POST.

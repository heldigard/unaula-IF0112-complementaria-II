Contenido Teórico

¿Por qué FastAPI?

  • Framework Python moderno, rápido y fácil de aprender.
  • Validación automática de datos con Pydantic.
  • Documentación interactiva generada automáticamente en /docs (Swagger UI).
  • Ideal para proyectos IoT porque es liviano y corre en cualquier PC con Python.

SQLite para IoT

  • Base de datos embebida: no necesita servidor aparte.
  • Se guarda en un solo archivo (.db) que puedes copiar y revisar.
  • Soporta SQL estándar: CREATE TABLE, INSERT, SELECT.
  • Perfecta para prototipos y proyectos universitarios.

Endpoints mínimos

  • POST /datos → Recibe JSON del ESP32 y lo guarda en BD.
  • GET /datos → Lista todos los registros almacenados.
  • GET /datos/latest → Devuelve el último registro insertado.

CORS y red local

  • CORS permite que un dashboard web (E5) consulte tu API desde el navegador.
  • La API debe correr en la IP local de tu PC para que el ESP32 la alcance.
  • Verifica que PC y ESP32 estén en la misma red WiFi.

Actividades Prácticas

🛠️ Actividad 1: FastAPI "Copy-Paste-Run" (25 min)

Objetivo: Tener una API corriendo en tu laptop en menos de 10 minutos.

  1. Abre CMD o PowerShell en Windows y crea una carpeta:
mkdir C:\smapi-api
cd C:\smapi-api
python -m venv venv
venv\Scripts\activate
pip install fastapi uvicorn
  1. Crea un archivo main.py y pega este código mínimo:
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "API IoT funcionando"}

@app.post("/datos")
def recibir_datos(temp: float, hum: float, luz: float):
    return {"recibido": {"temp": temp, "hum": hum, "luz": luz}}

@app.get("/datos")
def listar_datos():
    return {"datos": []}
  1. Corre la API y abre http://localhost:8000/docs en el navegador:
uvicorn main:app --reload
  1. Prueba POST /datos desde Swagger con valores de prueba. Si ves respuesta 200, avanza a la Actividad 2.

🛠️ Actividad 2: SQLite Paso a Paso (25 min)

Objetivo: Guardar datos de verdad en una base de datos local.

Reemplaza main.py con este código completo (copia y pega):

import sqlite3
from fastapi import FastAPI
from pydantic import BaseModel
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

DB_NAME = "sensores.db"

def init_db():
    conn = sqlite3.connect(DB_NAME)
    cursor = conn.cursor()
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS sensores (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            temperatura REAL,
            humedad REAL,
            luz REAL,
            timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
        )
    """)
    conn.commit()
    conn.close()

class Lectura(BaseModel):
    temperatura: float
    humedad: float
    luz: float

@app.on_event("startup")
def startup():
    init_db()

@app.post("/datos")
def guardar_dato(lectura: Lectura):
    conn = sqlite3.connect(DB_NAME)
    cursor = conn.cursor()
    cursor.execute(
        "INSERT INTO sensores (temperatura, humedad, luz) VALUES (?, ?, ?)",
        (lectura.temperatura, lectura.humedad, lectura.luz)
    )
    conn.commit()
    conn.close()
    return {"status": "guardado"}

@app.get("/datos")
def listar_datos(limit: int = 100):
    conn = sqlite3.connect(DB_NAME)
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM sensores ORDER BY timestamp DESC LIMIT ?", (limit,))
    filas = cursor.fetchall()
    conn.close()
    return {"datos": filas}

@app.get("/datos/latest")
def ultimo_dato():
    conn = sqlite3.connect(DB_NAME)
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM sensores ORDER BY timestamp DESC LIMIT 1")
    fila = cursor.fetchone()
    conn.close()
    return {"dato": fila}

Pasos:

  1. Guarda el archivo, reinicia uvicorn main:app --reload
  2. Ve a http://localhost:8000/docs
  3. Envía un POST /datos con valores de prueba
  4. Luego GET /datos y confirma que aparece el registro

🛠️ Actividad 3: ESP32 → API (15 min)

Objetivo: Conectar tu firmware al mundo real.

  1. Descubre tu IP local en Windows (necesaria para que el ESP32 te encuentre):
ipconfig

Busca algo como IPv4: 192.168.1.X bajo tu adaptador WiFi.

  1. En tu código ESP32, cambia la URL de destino. Si antes enviabas a ThingSpeak, ahora envía a:
String serverUrl = "http://192.168.1.X:8000/datos";
  1. Compila y sube el sketch. Abre el Monitor Serial a 115200 baudios.
  2. Verifica que la respuesta sea HTTP 200 y que el dato aparezca en GET /datos de Swagger.

🔧 Troubleshooting Rápido (Windows)

SíntomaSolución
'uvicorn' no se reconoceAsegúrate de activar el entorno: venv\Scripts\activate
ESP32 no conecta a la APIVerifica que PC y ESP32 estén en la misma red WiFi. Prueba hacer ping a la IP.
Error CORS en navegadorConfirma que el middleware CORS esté en main.py (ver Actividad 2).
Puerto 8000 ocupadoMata el proceso: taskkill /F /IM python.exe o usa otro puerto: --port 8001

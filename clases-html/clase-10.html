Contenido Teórico

¿Por qué FastAPI?

  • Framework Python moderno, rápido y fácil de aprender.
  • Validación automática de datos con Pydantic.
  • Documentación interactiva generada automáticamente en /docs (Swagger UI).
  • Ideal para proyectos IoT porque es liviano y corre en cualquier PC con Python.

SQLite para IoT

  • Base de datos embebida: no necesita servidor aparte.
  • Se guarda en un solo archivo (.db) que puedes copiar y revisar.
  • Soporta SQL estándar: CREATE TABLE, INSERT, SELECT.
  • Perfecta para prototipos y proyectos universitarios.

Endpoints mínimos

  • POST /datos → Recibe JSON del ESP32 y lo guarda en BD.
  • GET /datos → Lista todos los registros almacenados.
  • GET /datos/latest → Devuelve el último registro insertado.

CORS y red local

  • CORS permite que un dashboard web (E5) consulte tu API desde el navegador.
  • La API debe correr en la IP local de tu PC para que el ESP32 la alcance.
  • Verifica que PC y ESP32 estén en la misma red WiFi.

Actividades Prácticas

Actividad 1 (25 min): Crear una API FastAPI con POST /datos y GET /datos. Probar con Thunder Client, Postman o curl.

Actividad 2 (25 min): Conectar la API a SQLite. Crear tabla sensores e insertar datos de prueba. Verificar en Swagger UI.

Actividad 3 (15 min): Configurar el ESP32 (o simulador) para enviar JSON por HTTP POST a la IP local del compañero. Validar que la BD recibe el dato.

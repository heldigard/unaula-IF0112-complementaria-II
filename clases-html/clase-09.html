🔄 IT vs OT: Dos Mundos Convergentes

Aspecto 💻 IT ⚙️ OT
Enfoque Procesamiento de datos, software Control de equipos físicos
Prioridad Seguridad de datos, confidencialidad Disponibilidad, seguridad física
Latencia Tolerante (ms-seg) Crítica (<10ms)
Ejemplos Servidores, ERP, CRM PLC, SCADA, sensores industriales

🎯 Convergencia IT/OT

El IoT une ambos mundos: datos de sensores OT se procesan con tecnologías IT (cloud, analytics) para generar valor de negocio.

⚡ Edge Computing

📝 Definición

Procesamiento de datos cerca de la fuente (dispositivos), reduciendo latencia y ancho de banda.

Ventajas del Edge

  • Baja latencia: 1-10 ms (vs 100-500 ms en cloud).
  • Independencia de red: Funciona offline.
  • Privacidad: Datos sensibles no salen del sitio.
  • Ancho de banda: Solo envía datos filtrados a la nube.

Casos de Uso Edge

  • Vehículos autónomos: Decisiones de frenado en <10ms.
  • Control industrial: Respuesta inmediata en producción.
  • Monitoreo médico: Alertas instantáneas sin depender de internet.

☁️ Cloud Computing

📝 Definición

Procesamiento y almacenamiento en servidores remotos accesibles por internet.

Ventajas del Cloud

  • Escalabilidad: Recursos bajo demanda.
  • Costos: Pago por uso, sin inversión inicial.
  • Machine Learning: Entrenamiento de modelos con grandes datasets.
  • Acceso global: Dashboards desde cualquier lugar.

Proveedores Cloud IoT

  • AWS IoT Core
  • Microsoft Azure IoT Hub
  • Google Cloud IoT

📊 Edge vs Cloud: Comparación

Criterio ⚡ Edge ☁️ Cloud
Latencia 1-10 ms 100-500 ms
Costo Alto inicial (hardware) Bajo inicial, variable mensual
Procesamiento Local, limitado Ilimitado (escalable)
Conectividad No requerida Requerida
Mejor para Control en tiempo real Análisis histórico, ML

💡 Regla Práctica

Edge para control en tiempo real.
Cloud para análisis, almacenamiento y ML.
Híbrida para la mayoría de proyectos IoT.

🏗️ Arquitectura IoT de 3 Capas

☁️ CAPA 3: Cloud

Funciones: Análisis histórico, ML, dashboards empresariales.

Ejemplos: AWS IoT, ThingSpeak, Blynk

⚡ CAPA 2: Edge

Funciones: Filtrado, agregación, decisiones locales.

Ejemplos: Raspberry Pi, Gateway IoT

🔧 CAPA 1: Dispositivos

Funciones: Sensores, actuadores, control básico.

Ejemplos: ESP32, Arduino, sensores

Flujo de Datos

🔧 Dispositivos → ⚡ Edge (filtra) → ☁️ Cloud (analiza)

📝 Actividad: Diseño Arquitectónico

🎯 Instrucciones

En equipos, diseñen la arquitectura para su proyecto de monitoreo ambiental:

  1. ¿Qué procesamiento harán en el Edge (ESP32)?
  2. ¿Qué datos enviarán al Cloud?
  3. ¿Qué decisiones tomarán localmente vs remotamente?
  4. Dibujen el flujo de datos entre capas.

Ejemplo de Respuesta

Edge (ESP32): Leer sensor cada segundo, calcular promedio cada minuto, alertar si temperatura >30°C.

Cloud (ThingSpeak): Recibir promedios cada minuto, mostrar gráficos históricos, alertas por email.

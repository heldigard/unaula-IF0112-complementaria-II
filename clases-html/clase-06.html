Estructura de un Programa Arduino

Todo programa Arduino tiene dos funciones obligatorias:

1. setup() - Configuración

  • Se ejecuta una sola vez al inicio
  • Configura pines, inicia comunicación

2. loop() - Bucle Principal

  • Se ejecuta infinitamente
  • Aquí va la lógica principal
// Ejemplo mínimo
void setup() {
    // Configuración inicial
    Serial.begin(115200);
    pinMode(2, OUTPUT);  // LED integrado
}

void loop() {
    // Código que se repite
    digitalWrite(2, HIGH);
    delay(1000);
    digitalWrite(2, LOW);
    delay(1000);
}
Orden de ejecución: ENCENDIDO → setup() → loop() → loop() → loop()...

Control de GPIO

GPIO = General Purpose Input/Output (Entrada/Salida de Propósito General)

Son los pines del microcontrolador que pueden configurarse como:
  • Entrada (INPUT): Leer señales (botones, sensores)
  • Salida (OUTPUT): Enviar señales (LEDs, actuadores)
  • Entrada con pull-up (INPUT_PULLUP): Entrada con resistencia interna activada

Funciones Básicas

FunciónDescripciónEjemplo
pinMode(pin, mode)Configura pinINPUT, OUTPUT, INPUT_PULLUP
digitalWrite(pin, value)Escribe digitalHIGH, LOW
digitalRead(pin)Lee digitalDevuelve HIGH/LOW
analogRead(pin)Lee analógicoDevuelve 0-4095 (ESP32)
delay(ms)Pausadelay(1000) = 1 segundo
millis()Tiempo transcurridoDesde inicio en ms

Pines ESP32 DevKit

  • GPIO2: LED integrado (azul)
  • GPIO4: DHT22 (recomendado)
  • GPIO15: Botón (con pull-up)
  • GPIO34: ADC (LDR)

Proyectos Básicos

Proyecto 1: LED Blink

📥 Descargar .ino

const int LED = 2;  // LED integrado

void setup() {
    pinMode(LED, OUTPUT);
}

void loop() {
    digitalWrite(LED, HIGH);
    delay(1000);        // 1 segundo encendido
    digitalWrite(LED, LOW);
    delay(1000);        // 1 segundo apagado
}

Proyecto 2: Botón + LED

📥 Descargar .ino

const int LED = 2;
const int BOTON = 15;

void setup() {
    pinMode(LED, OUTPUT);
    pinMode(BOTON, INPUT_PULLUP);
    Serial.begin(115200);
}

void loop() {
    if (digitalRead(BOTON) == LOW) {  // Presionado
        digitalWrite(LED, HIGH);
        Serial.println("Botón presionado");
    } else {
        digitalWrite(LED, LOW);
    }
    delay(100);
}
INPUT_PULLUP: Activa resistencia interna. Botón presionado = LOW, suelto = HIGH.

Lectura de Sensores

Sensor LDR (Luz)

📥 Descargar .ino

const int LDR = 34;  // Pin analógico

void setup() {
    Serial.begin(115200);
}

void loop() {
    int valor = analogRead(LDR);     // 0-4095
    int porcentaje = map(valor, 0, 4095, 0, 100);
    
    Serial.print("Luz: ");
    Serial.print(porcentaje);
    Serial.println("%");
    
    delay(500);
}

Sensor DHT22 (Temperatura/Humedad)

Instalar librería: Sketch → Include Library → Manage Libraries → "DHT sensor library"

📥 Descargar .ino

#include "DHT.h"

const int DHT_PIN = 4;
DHT dht(DHT_PIN, DHT22);

void setup() {
    Serial.begin(115200);
    dht.begin();
}

void loop() {
    float temp = dht.readTemperature();
    float hum = dht.readHumidity();
    
    if (isnan(temp) || isnan(hum)) {
        Serial.println("Error leyendo DHT22");
    } else {
        Serial.print("Temp: ");
        Serial.print(temp);
        Serial.print("°C  Hum: ");
        Serial.print(hum);
        Serial.println("%");
    }
    
    delay(2000);  // DHT22 requiere 2s entre lecturas
}

Conexión DHT22

VCC  → 3.3V
GND  → GND
DATA → GPIO4 (con pull-up 10KΩ a 3.3V)

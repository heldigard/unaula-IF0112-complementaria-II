🔀 Diagrama de Flujo: Proceso de Conexión WiFi

💻 Código Básico Explicado Paso a Paso

#include <WiFi.h>

// Credenciales de tu red WiFi
// ⚠️ CAMBIA ESTOS VALORES por tu red real
const char* ssid = "NombreDeTuRed";
const char* password = "Contrasena";

void setup() {
    // 1. Iniciar comunicación serial para ver mensajes
    Serial.begin(115200);
    
    // 2. Iniciar conexión WiFi
    // El ESP32 comienza a buscar la red y negociar conexión
    WiFi.begin(ssid, password);
    
    // 3. Mostrar mensaje mientras conecta
    Serial.print("Conectando");
    
    // 4. BLOQUEANTE: Esperar hasta conectar
    // while() bloquea el programa hasta que se cumpla la condición
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);           // Esperar 500ms
        Serial.print(".");    // Mostrar progreso
    }
    
    // 5. ¡Conectado! Mostrar información
    Serial.println("\n¡Conectado exitosamente!");
    Serial.print("Dirección IP asignada: ");
    Serial.println(WiFi.localIP());  // Ej: 192.168.1.100
    Serial.print("Intensidad de señal: ");
    Serial.print(WiFi.RSSI());       // Ej: -45 dBm
    Serial.println(" dBm");
}

void loop() {
    // En loop() puedes verificar si sigue conectado
    // y reconectar si es necesario
}
🔍 ¿Por qué usar while() bloqueante?

El while() evita que el programa continúe sin conexión. Es útil en setup() porque necesitamos WiFi antes de iniciar otros servicios (servidor web, sensores, etc.). En producción, se usa con timeout para no bloquear indefinidamente.

📊 Estados WiFi: El "Estado de Ánimo" del ESP32

El ESP32 pasa por diferentes estados durante la conexión. Conocerlos te ayuda a depurar problemas:

Estado (Código) Significado ¿Qué hacer?
WL_IDLE_STATUS Inicializando / Inactivo Esperar, es normal al inicio
WL_SCAN_COMPLETED Escaneo de redes completado Listo para seleccionar red
WL_CONNECTED ✅ ¡Conectado exitosamente! Puedes enviar datos
WL_CONNECT_FAILED ❌ Falló la conexión Revisar contraseña
WL_CONNECTION_LOST Conexión perdida Reconectar automáticamente
WL_DISCONNECTED Desconectado Llamar WiFi.begin() de nuevo
WL_NO_SSID_AVAIL Red no encontrada Verificar nombre SSID

🔧 Funciones Útiles de Información de Red

Una vez conectado, puedes obtener información valiosa sobre tu conexión:

Función Retorna Ejemplo de uso
WiFi.localIP() IP local asignada 192.168.1.100
WiFi.RSSI() Intensidad señal (dBm) -45 (buena), -85 (débil)
WiFi.macAddress() Dirección MAC 24:6F:28:A4:B2:C1
WiFi.gatewayIP() IP del router 192.168.1.1
WiFi.subnetMask() Máscara de subred 255.255.255.0
WiFi.SSID() Nombre de red conectada "MiRedWiFi"
📶 Interpretando RSSI (Intensidad de Señal):
  • -30 a -50 dBm: Señal excelente (cerca del router)
  • -50 a -65 dBm: Señal buena
  • -65 a -75 dBm: Señal regular (puede haber intermitencias)
  • -75 a -85 dBm: Señal débil (posibles desconexiones)
  • Menos de -85 dBm: Muy débil (probablemente no funcione)

🚨 Guía de Troubleshooting WiFi

¿Problemas conectando tu ESP32? Esta guía te ayuda a diagnosticar y solucionar los errores más comunes.

❌ Errores Comunes y Soluciones

Síntoma/Error Causa Probable Solución
"WL_NO_SSID_AVAIL" o puntos infinitos El ESP32 no encuentra la red WiFi • Verificar que escribiste bien el SSID
• Revisar mayúsculas/minúsculas
• Asegurar que el router esté encendido
• El SSID no debe tener espacios al inicio/final
"WL_CONNECT_FAILED" Contraseña incorrecta • Revisar contraseña caracter por caracter
• Verificar caracteres especiales
• Asegurar que no hay espacios extras
Monitor Serial vacío Baudios incorrectos o cable mal conectado • Configurar Monitor Serial a 115200 baudios
• Verificar cable USB de datos (no solo carga)
• Presionar botón RST en el ESP32
Se conecta pero pierde IP Señal débil o router con DHCP limitado • Acercar ESP32 al router
• Verificar RSSI (debe ser > -70 dBm)
• Reiniciar router si es necesario
"Brownout detector" Alimentación insuficiente • Usar cable USB de mejor calidad
• Conectar a puerto USB 2.0 en lugar de 3.0
• Usar fuente de alimentación externa
"Connection lost" frecuente Interferencia o señal inestable • Implementar reconexión automática en loop()
• Cambiar canal del router (1, 6 o 11)
• Alejar de microondas o bluetooth

💡 Código de Reconexión Automática

Para proyectos en producción, implementa reconexión automática en el loop():

void loop() {
  // Verificar conexión WiFi
  if (WiFi.status() != WL_CONNECTED) {
    Serial.println("⚠️ WiFi desconectado. Reconectando...");
    WiFi.reconnect();
    
    // Esperar reconexión con timeout
    int intentos = 0;
    while (WiFi.status() != WL_CONNECTED && intentos < 10) {
      delay(500);
      Serial.print(".");
      intentos++;
    }
    
    if (WiFi.status() == WL_CONNECTED) {
      Serial.println("\n✅ Reconectado!");
    } else {
      Serial.println("\n❌ Falló reconexión");
    }
  }
  
  // Tu código principal aquí
  delay(1000);
}
⚠️ Consejo para el Simulador Wokwi:

En Wokwi, las redes WiFi son simuladas. Los ejercicios funcionarán sin configurar SSID real, pero cuando pases a hardware físico, debes reemplazar los valores con tu red real.

🏗️ Arquitectura del Servidor Web

💻 Código del Servidor Web

Este código crea un servidor web que muestra una página con el estado de un sensor:

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "TU_RED";
const char* password = "TU_PASS";

WebServer server(80);  // Puerto 80 (HTTP estándar)

// Función que responde a la ruta principal "/"
void handleRoot() {
    // Crear página HTML dinámica
    String html = "";
    html += "";
    html += "";
    html += "ESP32 IoT";
    html += "";
    html += "";
    html += "";
    html += "
🌐 Servidor ESP32
";
    html += "
";
    html += "
Datos del Sensor
";
    html += "
Temperatura: 25.5°C
";
    html += "
Humedad: 60%
";
    html += "
";
    html += "";
    html += "";
    
    // Enviar respuesta HTTP 200 OK con el HTML
    server.send(200, "text/html", html);
}

void setup() {
    Serial.begin(115200);
    
    // Conectar a WiFi
    WiFi.begin(ssid, password);
    Serial.print("Conectando a WiFi");
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }
    
    // Mostrar IP del servidor
    Serial.println("\n✅ Conectado!");
    Serial.print("🌐 Servidor web en: http://");
    Serial.println(WiFi.localIP());
    
    // Configurar rutas del servidor
    server.on("/", handleRoot);  // Ruta principal
    
    // Iniciar servidor
    server.begin();
    Serial.println("✅ Servidor iniciado");
}

void loop() {
    // Escuchar y responder peticiones de clientes
    server.handleClient();
}
🌐 ¿Cómo acceder?

Abre cualquier navegador (Chrome, Firefox, Safari) y escribe la IP mostrada en el Serial Monitor. Ejemplo: http://192.168.1.100

🔧 Rutas HTTP Comunes

Puedes crear diferentes rutas para diferentes funciones:

// En setup():
server.on("/", handleRoot);           // Página principal
server.on("/led/on", handleLedOn);    // Encender LED
server.on("/led/off", handleLedOff);  // Apagar LED
server.on("/api/data", handleData);   // API JSON con datos del sensor

💻 Código Completo para ThingSpeak

#include 
#include 
#include 

// Configuración WiFi
const char* ssid = "TU_RED_WIFI";
const char* password = "TU_CONTRASENA";

// Configuración ThingSpeak
const char* apiKey = "TU_WRITE_API_KEY";  // Reemplazar con tu API Key
const char* server = "http://api.thingspeak.com/update";

// Configuración DHT22
#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

void setup() {
    Serial.begin(115200);
    dht.begin();
    
    // Conectar WiFi
    WiFi.begin(ssid, password);
    Serial.print("Conectando a WiFi");
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }
    Serial.println("\n✅ WiFi conectado!");
}

void loop() {
    // Leer datos del sensor
    float temperatura = dht.readTemperature();
    float humedad = dht.readHumidity();
    
    // Verificar lectura válida
    if (isnan(temperatura) || isnan(humedad)) {
        Serial.println("❌ Error leyendo DHT22");
        return;
    }
    
    // Enviar a ThingSpeak
    enviarDatos(temperatura, humedad);
    
    // Esperar 15 segundos (límite de cuenta gratuita)
    delay(15000);
}

void enviarDatos(float temp, float hum) {
    if (WiFi.status() != WL_CONNECTED) {
        Serial.println("❌ Sin conexión WiFi");
        return;
    }
    
    HTTPClient http;
    
    // Construir URL con datos
    String url = String(server) + "?api_key=" + apiKey;
    url += "&field1=" + String(temp);
    url += "&field2=" + String(hum);
    
    Serial.print("Enviando: ");
    Serial.println(url);
    
    http.begin(url);
    int httpCode = http.GET();
    
    if (httpCode == 200) {
        Serial.println("✅ Datos enviados exitosamente!");
    } else {
        Serial.print("❌ Error HTTP: ");
        Serial.println(httpCode);
    }
    
    http.end();
}
⚠️ Limitaciones de Cuenta Gratuita:
  • Máximo 3 mensajes por minuto (cada 20 segundos)
  • 4 canales públicos como máximo
  • Datos se almacenan por tiempo limitado

📊 Formato de la URL HTTP GET

http://api.thingspeak.com/update?api_key=TU_API_KEY&field1=25.5&field2=60.0
  • api_key: Tu clave secreta de escritura
  • field1: Valor para el campo 1 (Temperatura)
  • field2: Valor para el campo 2 (Humedad)
  • Puedes agregar hasta 8 campos: field1, field2, ..., field8

📚 Glosario de Términos de Red

Conceptos importantes para entender la conectividad WiFi:

SSID
Service Set Identifier - Nombre de la red WiFi (ej: "MiCasa_WiFi")
WPA2
Protocolo de seguridad WiFi más común. Encripta la comunicación.
DHCP
Asigna IPs automáticamente a los dispositivos que se conectan.
IP Estática vs Dinámica
Estática: fija. Dinámica: cambia cada vez (asignada por DHCP).
Puerto 80
Puerto estándar para HTTP (webs). HTTPS usa el 443.
HTTP GET vs POST
GET: solicita datos (leer). POST: envía datos (escribir).
API Key
Clave secreta para autenticarse en un servicio API.
JSON
Formato de datos {"temp": 25.5, "hum": 60}
MAC Address
Identificador único de hardware (ej: 24:6F:28:A4:B2:C1)
RSSI
Received Signal Strength Indicator. Mide la fuerza de señal WiFi.

Objetivo del proyecto final

Aprendizaje clave

El proyecto final integra TODO lo aprendido: hardware (sensores/actuadores), conectividad (WiFi/MQTT), software (Arduino/Python), visualización (dashboard/Grafana), y documentación. Trabajo en equipo de 3-4 estudiantes, con exposición en semana 16. Hardware es opcional: usar simuladores (Wokwi, Tinkercad) o demo del docente.

Disenar y prototipar un sistema IoT completo que resuelva un problema real, integrando hardware, software, conectividad, visualizacion y documentacion.

Términos Clave del Proyecto Final

Término Definición Ejemplo
Blynk Plataforma no-code para crear apps móviles IoT con drag-and-drop Controlar ESP32 desde smartphone sin programar app nativa
KPI Key Performance Indicator - métrica cuantificable para medir éxito "Ahorro del 40% de agua" o "Tiempo de respuesta < 2 segundos"
Geofencing Delimitación virtual geográfica que dispara acciones al cruzarse Alerta cuando mascota sale del perímetro definido
Anti-hammering Protección contra intentos repetidos de autenticación (ataques de fuerza bruta) Bloquear teclado por 5 minutos después de 3 intentos fallidos
P-P-D-C Personas - Procesos - Datos - Cosas (modelo de 4 pilares de IoT) Identificar roles (personas), flujos (procesos), qué se recolecta (datos) y dispositivos (cosas)
OLED Organic Light-Emitting Diode - pantalla de bajo consumo para microcontroladores Pantalla pequeña (128x64) para mostrar datos sin laptop
PMS5003 Sensor de partículas que mide PM1.0, PM2.5, PM10 Detector de calidad de aire que mide material particulado
Waterproof Resistente al agua (IP65+) Caja protectora para sensor IoT exterior contra lluvia

Requisitos minimos

Hardware

  • Microcontrolador (ESP32 o similar).
  • Minimo 2 sensores diferentes.
  • Minimo 1 actuador.
  • Circuito de alimentacion apropiado.

Software

  • Lectura de sensores funcionando.
  • Logica de decision implementada.
  • Actuador controlado segun la logica.
  • Conectividad WiFi activa.
  • Comunicacion con nube/servidor.

Conectividad

  • Protocolo de comunicacion (MQTT/HTTP).
  • Interfaz web o app movil.
  • Visualizacion de datos en tiempo real.

Documentacion

  • Diagrama de arquitectura.
  • Diagrama de conexiones fisicas.
  • Codigo comentado.
  • Manual de usuario.
  • Video demostrativo.

Ejemplos de proyectos exitosos

Proyecto 1: Sistema de riego inteligente

  • ESP32 + DHT22 + sensor humedad + bomba.
  • App Blynk con modo automatico y manual.
  • Ahorro 40% de agua vs riego manual.
# Fragmento de codigo (Blynk)
void checkHumedad() {
  int humedad = analogRead(HUMEDAD_PIN);
  humedad = map(humedad, 0, 4095, 0, 100);

  if (humedad < 30) {
    digitalWrite(BOMBA_PIN, HIGH);
    Blynk.notify("Riego activado");
  } else if (humedad > 60) {
    digitalWrite(BOMBA_PIN, LOW);
  }
}

Proyecto 2: Monitor de calidad del aire

  • ESP32 + PMS5003 + SCD30 + OLED.
  • Alertas si PM2.5 > 25 ug/m3.
  • Autonomia 8h con bateria.

Proyecto 3: Cerradura inteligente

  • ESP32 + keypad + huella + servo.
  • Anti-hammering y logs en SD.

Proyecto 4: Seguimiento de mascotas

  • ESP32 + GPS + acelerometro.
  • Geofencing y autonomia 8 dias.

Fase 2 del Proyecto SMAI: Interacción mundo físico-virtual

📋 Prerrequisitos (de E1)

Para realizar esta evaluación debes haber completado:

  • E1 Investigación: Arquitectura del SMAI aprobada.
  • Kit de materiales: ESP32, DHT22, LDR, resistencias 10kΩ, LEDs, protoboard.
  • Arduino IDE instalado con librería DHT sensor library.

Nota: El circuito que montes en E2 será la base para E3 (conectividad WiFi).

Objetivo

Implementar el montaje físico (o simulado en Wokwi) de la capa de percepción del SMAI, logrando la lectura de variables ambientales y el control de actuadores locales.

Requisitos Técnicos

El prototipo debe demostrar las siguientes funcionalidades usando el hardware del Kit SMAI:

  • Lectura DHT22: Obtención de temperatura (°C) y humedad (%) con precisión de 1 decimal.
    • Librería requerida: DHT sensor library by Adafruit (v1.4.4 o superior).
    • Pin de datos: GPIO 4 (con resistencia pull-up de 10kΩ opcional).
    • Tiempo de estabilización: 2 segundos entre lecturas.
  • Lectura LDR: Mapeo del valor analógico a porcentaje de luz.
    • Pin analógico: GPIO 34 (canal ADC1 del ESP32).
    • Rango del ADC: 0-4095 (12 bits de resolución).
    • Función: map(valorADC, 0, 4095, 0, 100) para obtener porcentaje.
    • Circuito: Divisor de voltaje con resistencia de 10kΩ.
  • Salida Serial: Comunicación a 115200 baudios.
    • Formato: Serial.begin(115200) en el setup().
    • Visualización: Monitor Serial del Arduino IDE o puerto COM.
  • Lógica de Actuación: Control de LEDs indicadores.
    • LED Rojo (GPIO 2): Se enciende si temperatura ≥ 30°C.
    • LED Amarillo (GPIO 15): Se enciende si luz ≤ 20%.
    • Implementación: Función digitalWrite() basada en condicionales if.

🔌 Diagrama de Conexión Completo (E2)

El circuito de la E2 combina el DHT22 para temperatura/humedad y el LDR para luz, junto con 2 LEDs indicadores. Sigue estas conexiones exactas:

Conexiones Paso a Paso:

Componente Pin/Terminal Conecta a ESP32
DHT22 Pin 1 (VCC) 3.3V
Pin 2 (DATA) GPIO 4 + Resistencia 10kΩ a 3.3V
Pin 3 (NC) No conectar
Pin 4 (GND) GND
LDR
(fotorresistencia)		 Lado 1 3.3V
Lado 2 GPIO 34 (ADC1)
Lado 2 (también) Resistencia 10kΩ a GND
LED Rojo Ánodo (+) GPIO 2 (vía resistor 220Ω)
Cátodo (-) GND
LED Amarillo Ánodo (+) GPIO 15 (vía resistor 220Ω)
Cátodo (-) GND
⚠️ Consejos Importantes:
  • Resistencia pull-up DHT22: La resistencia de 10kΩ entre DATA y VCC es OBLIGATORIA. Sin ella, el sensor dará lecturas erráticas.
  • Divisor de voltaje LDR: El LDR debe formar un divisor con la resistencia de 10kΩ. Un lado del LDR a 3.3V, el otro lado conecta a GPIO 34 Y a la resistencia de 10kΩ que va a GND.
  • GPIO 34: Este pin es solo entrada y usa el canal ADC1, que funciona bien con WiFi activado.
  • GPIO 4: Para el DHT22 es digital, no necesita ser pin ADC.

  • Gemelo Digital (Wokwi): Entrega del link del proyecto en Wokwi funcionando al 100%.

✅ Lista de Verificación Pre-Entrega

Antes de presentar tu E2, verifica que:

  • ☐ El código compila sin errores en Arduino IDE
  • ☐ El Monitor Serial muestra valores de temperatura, humedad y luz cada 2 segundos
  • ☐ Los LEDs se encienden cuando se cumplen las condiciones (temp ≥ 30°C, luz ≤ 20%)
  • ☐ Los valores tienen sentido (temperatura entre 15-35°C, humedad entre 30-90%, luz entre 0-100%)
  • ☐ Si usas Wokwi: el proyecto está público y el link funciona
  • ☐ Si usas hardware real: tienes todo el circuito montado y funcionando
  • ☐ El archivo se llama E2_Apellido_Nombre.ino

Entregables

  • Código fuente: Archivo E2_Apellido_Nombre.ino subido a Canvas
  • Evidencia visual: Captura de pantalla del Monitor Serial mostrando datos, o link de Wokwi
  • Video (opcional para presencial, obligatorio para remoto): Máximo 60 segundos demostrando el funcionamiento
💡 Tip: Si presentas en persona, trae tu laptop con el código listo para compilar y demostrar. Si usas hardware real, verifica que todos los cables estén bien conectidos antes de la clase.

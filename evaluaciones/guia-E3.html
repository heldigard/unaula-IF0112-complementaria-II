Fase 3 del Proyecto SMAI: Conectividad IoT a través de redes e Internet

📋 Prerrequisitos (de E2)

Para realizar esta evaluación debes tener funcionando:

  • E2 Prototipo: Circuito con ESP32 + DHT22 + LDR leyendo datos correctamente.
  • Código de E2 funcionando: lectura de sensores cada 2 segundos, LEDs respondiendo a umbrales.
  • Monitor Serial mostrando valores de temperatura, humedad y luz en formato legible.

Nota: Esta evaluación NO requiere modificar el circuito de E2, solo agregar conectividad WiFi al código existente. El mismo hardware servirá para E4.

💡 Si no tienes WiFi en casa: Puedes usar el hotspot de tu celular para probar. También puedes hacer la evaluación en la universidad usando la red WiFi del campus (debes configurar las credenciales según la red disponible).

🎯 ¿Qué vas a lograr en esta evaluación?

Resultado final: Verás gráficas en tiempo real de tus sensores desde cualquier dispositivo (celular, PC, tablet)

Objetivo

Desarrollar el firmware de conectividad para el SMAI, permitiendo que el microcontrolador ESP32 transmita datos ambientales a una plataforma en la nube a través de protocolos IP.

📝 Código Base para E3 (Ejemplo Completo)

Este es un código de ejemplo funcional. Debes adaptarlo con tus credenciales de WiFi y API Key de ThingSpeak:

#include <WiFi.h>
#include <HTTPClient.h>
#include <DHT.h>

// ============ CONFIGURACIÓN WiFi ============
const char* ssid = "NOMBRE_DE_TU_WIFI";      // ← Cambiar
const char* password = "CONTRASENA_WIFI";    // ← Cambiar

// ============ CONFIGURACIÓN THINGSPEAK ============
const char* apiKey = "TU_API_KEY_AQUI";      // ← Cambiar (Write API Key)
const char* server = "http://api.thingspeak.com/update";

// ============ CONFIGURACIÓN SENSORES ============
#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);
const int ldrPin = 34;  // GPIO34 para LDR

// ============ VARIABLES DE TIEMPO ============
unsigned long lastTime = 0;
unsigned long timerDelay = 20000;  // 20 segundos

void setup() {
  Serial.begin(115200);
  dht.begin();
  
  // Conectar a WiFi
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  
  Serial.print("Conectando a WiFi");
  int intentos = 0;
  while (WiFi.status() != WL_CONNECTED && intentos < 20) {
    delay(500);
    Serial.print(".");
    intentos++;
  }
  
  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\n✅ WiFi conectado!");
    Serial.print("📡 IP asignada: ");
    Serial.println(WiFi.localIP());
  } else {
    Serial.println("\n❌ No se pudo conectar a WiFi");
  }
}

void loop() {
  // Enviar datos cada 20 segundos usando millis()
  if ((millis() - lastTime) > timerDelay) {
    
    // Verificar conexión WiFi
    if (WiFi.status() == WL_CONNECTED) {
      
      // Leer sensores
      float temperatura = dht.readTemperature();
      float humedad = dht.readHumidity();
      int valorLuz = analogRead(ldrPin);
      
      // Verificar lecturas válidas
      if (isnan(temperatura) || isnan(humedad)) {
        Serial.println("❌ Error leyendo DHT22");
      } else {
        
        // Mostrar en Serial lo que vamos a enviar
        Serial.println("\n📊 Datos a enviar:");
        Serial.print("  Temperatura: "); Serial.print(temperatura); Serial.println("°C");
        Serial.print("  Humedad: "); Serial.print(humedad); Serial.println("%");
        Serial.print("  Luz: "); Serial.println(valorLuz);
        
        // Enviar a ThingSpeak
        enviarDatos(temperatura, humedad, valorLuz);
      }
      
    } else {
      Serial.println("⚠️ WiFi desconectado. Intentando reconectar...");
      WiFi.reconnect();
    }
    
    lastTime = millis();
  }
}

void enviarDatos(float temp, float hum, int luz) {
  HTTPClient http;
  
  // Construir URL
  String url = String(server) + "?api_key=" + apiKey;
  url += "&field1=" + String(temp);
  url += "&field2=" + String(hum);
  url += "&field3=" + String(luz);
  
  Serial.print("\n🌐 Enviando a ThingSpeak...");
  
  http.begin(url);
  int httpCode = http.GET();
  
  if (httpCode == 200) {
    Serial.println(" ✅ Exitoso!");
    Serial.println("   Código HTTP: " + String(httpCode));
  } else {
    Serial.println(" ❌ Error!");
    Serial.println("   Código HTTP: " + String(httpCode));
  }
  
  http.end();  // ¡Importante! Liberar recursos
}
⚠️ Cambios obligatorios en el código:
  • Línea 6: "NOMBRE_DE_TU_WIFI" → tu red WiFi real
  • Línea 7: "CONTRASENA_WIFI" → tu contraseña WiFi
  • Línea 10: "TU_API_KEY_AQUI" → tu Write API Key de ThingSpeak

🔧 Requisitos Técnicos (Resumen)

Tu código debe cumplir estos requisitos mínimos:

✅ Conectividad WiFi
  • Usar WiFi.mode(WIFI_STA)
  • Configurar credenciales correctamente
  • Mostrar IP asignada en Serial
✅ Envío de Datos
  • Usar librería HTTPClient
  • Enviar cada 20 segundos (mínimo)
  • 3 campos: Temp, Hum, Luz
✅ Temporización
  • Usar millis() (NO delay)
  • Variable lastTime para control
  • Intervalo de 20000ms (20s)
✅ Robustez
  • Verificar WiFi.status()
  • Reconexión automática
  • Llamar http.end()

📖 Guía Paso a Paso: Configurar ThingSpeak

Sigue estos pasos para crear tu canal y obtener la API Key:

Paso 1: Crear Cuenta

  1. Ve a thingspeak.com
  2. Haz clic en "Sign Up" (usar correo institucional .edu si tienes)
  3. Verifica tu correo electrónico
  4. Inicia sesión

Paso 2: Crear un Nuevo Canal

  1. Haz clic en "Channels" en el menú superior
  2. Selecciona "My Channels"
  3. Haz clic en el botón verde "New Channel"
  4. Completa la información:
    • Name: "SMAI Monitor Ambiental" (o tu nombre)
    • Description: "Datos de temperatura, humedad y luz"
    • Field 1: Temperatura (°C)
    • Field 2: Humedad (%)
    • Field 3: Luz (0-4095)
  5. Haz clic en "Save Channel" (abajo de todo)

Paso 3: Obtener tu API Key (¡Importante!)

  1. En tu canal, haz clic en la pestaña "API Keys"
  2. Busca "Write API Key" (es un código de 16 caracteres)
  3. Copia este código y pégalo en tu código Arduino en la línea 10: 
    const char* apiKey = "ABCDEF1234567890";  // Tu Write API Key
  4. ⚠️ Guarda bien este código: Es la "contraseña" para enviar datos a TU canal

Paso 4: Hacer el Dashboard Público (30% de la nota)

Esto es CRÍTICO: El docente debe poder ver tu dashboard sin iniciar sesión.

  1. En tu canal, haz clic en "Sharing" (pestaña superior)
  2. Busca la opción "Make this channel public"
  3. Activa el checkbox ✅
  4. Haz clic en "Save"
  5. Ahora copia la URL de tu canal (estará en el navegador, algo como: https://thingspeak.com/channels/1234567)
  6. Esta URL es la que debes entregar en Canvas
⚠️ Verificación: Abre la URL en una pestaña de incógnito (Ctrl+Shift+N). Si ves los gráficos sin iniciar sesión, ¡está correcto!

Paso 5: Personalizar Gráficos (Opcional pero recomendado)

  1. En tu canal, haz clic en "Private View" o "Public View"
  2. Haz clic en el ícono de engranaje ⚙️ de cada gráfico
  3. Puedes cambiar:
    • Título del gráfico
    • Color de la línea
    • Rango del eje Y
    • Tipo de gráfico (línea, barra, etc.)
  4. Haz clic en "Save"

✅ Lista de Verificación Pre-Entrega

Antes de enviar tu E3, verifica cada ítem:

  • ☐ El código incluye WiFi.mode(WIFI_STA) y conecta a tu red WiFi
  • ☐ El Monitor Serial muestra "WiFi conectado" y la IP asignada (ej: 192.168.1.45)
  • ☐ Se ven mensajes "Enviando datos..." y "Datos enviados! Código: 200" cada 20 segundos
  • ☐ El Dashboard en la nube muestra datos actualizándose en tiempo real
  • ☐ Hay mínimo 3 widgets/gráficos: Temperatura, Humedad, Luz
  • ☐ Se usa millis() en lugar de delay() para la temporización
  • ☐ El código maneja reconexión automática si se pierde WiFi
  • ☐ El archivo se llama E3_Apellido_Nombre.ino
  • ☐ El link al dashboard es accesible públicamente (no requiere login)
⚠️ Errores Comunes a Evitar:
  • Usar delay(20000) en lugar de millis() (bloquea el sistema)
  • Olvidar llamar http.end() después de cada envío (fuga de memoria)
  • No verificar WiFi.status() antes de enviar (causa errores HTTP)
  • API Key incorrecta o canal no configurado en ThingSpeak/Ubidots
  • Enviar datos más rápido que el límite de la plataforma (15-20 segundos mínimo)

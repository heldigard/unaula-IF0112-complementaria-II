Fase 5 del Proyecto SMAI: Marco legal regulatorio y validación técnica

📋 Prerrequisitos (de E4)

Para realizar esta evaluación debes tener:

  • E4 Lógica: Firmware con máquina de estados funcionando (NORMAL, ALERTA_TEMP, ALERTA_LUZ).
  • Producto SMAI operativo: sensores leyendo, WiFi conectado, dashboard actualizándose.
  • Código finalizado y estable (será la base para E6).

Nota: Esta evaluación documenta el producto ya funcionando. Se crea la ficha técnica, manual de usuario y cumplimiento normativo. La documentación de E5 será entregada junto al producto final en E6.

Objetivo

Asegurar que el SMAI cumple con los estándares legales y técnicos del sector tecnológico en Colombia, incluyendo la privacidad de datos y la seguridad eléctrica.

Estructura del PDF (Obligatoria)

El documento unificado debe contener las siguientes secciones, siguiendo estándares de documentación técnica:

  • 1. Ficha Técnica del Producto (SMAI):
    • Especificaciones Eléctricas:
      • Voltaje de alimentación: 5V DC (Micro-USB tipo B).
      • Consumo máximo: ~250mA (con WiFi activo).
      • Consumo standby: ~80mA (modo ahorro).
      • Clase de protección: III (bajo voltaje).
    • Especificaciones de Sensores:
      • DHT22: Rango -40°C a 80°C, precisión ±0.5°C, ±2% HR.
      • LDR: Resistencia 1MΩ (oscuridad) a 10kΩ (luz).
    • Conectividad:
      • Protocolo: IEEE 802.11 b/g/n (WiFi 2.4GHz).
      • Seguridad: WPA2/WPA3.
      • API: HTTP GET a plataforma IoT (puerto 80) - opciones: ThingSpeak, Ubidots STEM, Arduino Cloud, etc.
  • 2. Política de Tratamiento de Datos Personales (Ley 1581 de 2012):
    • Identificación del Responsable: Nombre del estudiante/grupo.
    • Datos recolectados: Dirección IP del dispositivo, credenciales WiFi (almacenadas localmente).
    • Finalidad: Monitoreo ambiental y académico.
    • Derechos del titular: Acceso, rectificación, supresión (derechos ARCO).
    • Medidas de seguridad: Cifrado WPA2 en red, credenciales no compartidas públicamente.
  • 3. Manual de Instalación Eléctrica (Basado en RETIE):
    • Tipo de fuente: Adaptador USB 5V/1A con certificación de seguridad.
    • Protección: Fusible de 500mA en línea positiva.
    • Aislamiento: Caja plástica con IP20 (protección contra objetos sólidos).
    • Conexión a tierra: No aplica (clase III, doble aislamiento).
    • Advertencias: No operar en atmósferas explosivas, evitar exposición directa a agua.

Manual de Usuario

Se debe adjuntar un manual simplificado para el usuario final que incluya:

  • Instrucciones de conexión al WiFi.
  • Interpretación de las alertas visuales (LEDs).
  • Cómo acceder al Dashboard de visualización.

Formato de Entrega

  • Documento PDF unificado.
  • Lenguaje profesional y técnico.
  • Citas bibliográficas de las normas consultadas.

¿Qué es un Microcontrolador (MCU)?

Una computadora completa en un solo chip que integra CPU, memoria, puertos de entrada/salida y periféricos.

Componentes Principales

ComponenteFunciónEjemplo
CPUEjecuta instrucciones16-240 MHz
FlashAlmacena programa32 KB - 4 MB
RAMMemoria temporal2 KB - 520 KB
GPIOPines digitales14-34 pines
ADCLectura analógica10-12 bits

Arduino: La Revolución del Hardware Libre

Ventajas

  • Curva de aprendizaje suave
  • Documentación extensa
  • Costo: $5-25 USD
  • Miles de bibliotecas disponibles

Limitaciones

  • Sin WiFi nativo (requiere shields)
  • Memoria limitada (2 KB RAM)
  • Velocidad: 16 MHz

ESP32: El Estándar de Facto para IoT

¿Por qué ESP32 domina IoT? Combina potencia, conectividad (WiFi + Bluetooth) y bajo costo ($3-5 USD).

Especificaciones

Conexión Básica: DHT22 al ESP32

VCC (DHT22)  → 3.3V (ESP32)
GND (DHT22)  → GND (ESP32)
DATA (DHT22) → GPIO4 (ESP32)

Nota: Resistencia pull-up 10KΩ entre DATA y VCC

📚 Glosario de Términos de Hardware

Conceptos clave que debes conocer para trabajar con microcontroladores:

Término Significado Descripción
GPIO General Purpose Input/Output Pines de entrada/salida de propósito general
ADC Analog-to-Digital Converter Conversor de señal analógica a digital
PWM Pulse Width Modulation Modulación por ancho de pulso (control intensidad)
I2C Inter-Integrated Circuit Protocolo de comunicación entre circuitos integrados
SPI Serial Peripheral Interface Interfaz serie para periféricos (alta velocidad)
UART Universal Asynchronous Receiver-Transmitter Transmisor-receptor asíncrono universal
DAC Digital-to-Analog Converter Conversor de señal digital a analógica
SRAM Static Random Access Memory Memoria RAM estática (rápida, volátil)
Flash Flash Memory Memoria flash (almacena programa, no volátil)
💡 Nota importante: En el ESP32, los pines GPIO pueden configurarse como entrada o salida usando pinMode(). El ADC convierte voltajes (0-3.3V) en números digitales (0-4095 en ESP32).

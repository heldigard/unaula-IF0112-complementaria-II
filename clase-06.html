💡 ¿Por qué Arduino para Comenzar?

Ventajas: Curva de aprendizaje suave, IDE gratuito y multiplataforma, miles de bibliotecas disponibles, comunidad global activa, hardware económico ($10-30 USD), documentación extensa en español.

Limitaciones: No es un IDE profesional completo, gestión de proyectos grandes es difícil, no tiene debugger integrado.

Alternativas profesionales: PlatformIO + VSCode, ESP-IDF (nativo Espressif), MicroPython.

Términos Clave de Hardware y Programación

Nota: Los siguientes términos son fundamentales para comprender la programación de microcontroladores. Familiarizarse con ellos facilita el aprendizaje de Arduino/ESP32.
Término Definición Ejemplo en Arduino/ESP32
GPIO General Purpose Input/Output: Pines de entrada/salida de propósito general GPIO18 puede ser INPUT o OUTPUT según se configure
ESP32 Microcontrolador de Espressif con WiFi/BLE integrados, low-cost, comunidad grande La placa usada en este curso (reemplaza a Arduino clásico)
PWM Pulse Width Modulation: Modulación por ancho de pulso para simular salida analógica Controla brillo de LED variando el ancho del pulso
ADC Analog-to-Digital Converter: Convierte señales analógicas a valores digitales Lectura de LDR devuelve 0-4095 (12-bit) en ESP32
Pull-up Resistencia interna que mantiene un pin en estado HIGH cuando no está conectado INPUT_PULLUP evita lecturas erráticas cuando botón está abierto
Firmware Software de bajo nivel que controla el hardware directamente El código Arduino se convierte en firmware que ejecuta el ESP32
LDR Light Dependent Resistor: Resistencia que varía con la luz incidente Mayor luz = menor resistencia, se usa con divisor de voltaje
DHT11 Sensor digital de temperatura y humedad (rango: 0-50°C, 20-90% HR) Usa protocolo propio de un hilo, requiere librería DHT.h
isnan() Is Not a Number: Función C++ que verifica si un valor es inválido (NaN) Usado para detectar fallas de lectura del sensor DHT11
Baud Rate Velocidad de comunicación serial (bits por segundo) 115200 es estándar para ESP32, 9600 es compatible universal
Monitor Serial Herramienta para ver datos enviados por el microcontrolador vía USB Usa Serial.print() en código, abre con Ctrl+Shift+M
Error Común: Confundir pinMode() con digitalWrite(). pinMode() CONFIGURA el pin (una vez en setup), digitalWrite() ESCRIBE un valor (en loop, muchas veces). No configures pines repetidamente.

📐 Estructura de un Programa Arduino

🎯 Aprendizaje Clave

Todo programa Arduino tiene dos partes: setup() (configuración inicial única) y loop() (bucle infinito). Esta estructura es el fundamento de todo código embebido.

Todo programa Arduino tiene exactamente dos funciones obligatorias:

1. `setup()` - Configuración

  • Se ejecuta una sola vez al inicio
  • Se usa para configurar pines, iniciar comunicación, etc.
  • Equivalente al "constructor" o "inicializador"

2. `loop()` - Bucle Principal

  • Se ejecuta infinitamente después de setup()
  • Aquí va la lógica principal del programa
  • Cada iteración es un "ciclo" del programa

⚡ Funciones Básicas de Entrada/Salida

🎯 Aprendizaje Clave

Las funciones pinMode(), digitalWrite(), digitalRead() y analogRead() son los primitivos básicos para interactuar con el mundo físico desde el código.

Configuración y Digital

// Configurar pines
pinMode(pin, OUTPUT);        // Salida
pinMode(pin, INPUT);         // Entrada
pinMode(pin, INPUT_PULLUP);  // Con pull-up interno

// Escribir/leer digital
digitalWrite(pin, HIGH);     // 3.3V
digitalWrite(pin, LOW);      // 0V
int valor = digitalRead(pin); // HIGH o LOW

Analógico y PWM

// Leer ADC (0-4095 en ESP32)
int valor = analogRead(pin);

// PWM en ESP32
ledcSetup(channel, 5000, 8);  // 5kHz, 8-bit
ledcAttachPin(pin, channel);
ledcWrite(channel, 127);      // 50% brillo

Tiempo y Serial

// Pausas
delay(1000);              // 1 segundo (bloquea)
unsigned long t = millis(); // Tiempo desde inicio (no bloquea)

// Serial
Serial.begin(115200);
Serial.println("Valor: " + String(valor));
Serial.printf("Temp: %.2f C\n", temp);

📟 Monitor Serial: Herramienta de Depuración

Canal de comunicación entre el ESP32 y la computadora que permite ver valores de sensores en tiempo real, enviar comandos al microcontrolador, depurar errores en el código.

Velocidad (Baud Rate): 9600 (compatible universal), 115200 (estándar ESP32), 921600 (upload rápido).

IMPORTANTE: La velocidad en código debe coincidir con la del monitor serial.

💡 Proyecto 1: LED Blink (El "Hola Mundo" de Hardware)

🎯 Aprendizaje Clave

El proyecto Blink enseña la diferencia entre delay() (bloqueante) y millis() (no bloqueante). El enfoque no bloqueante es esencial para sistemas que deben hacer múltiples tareas simultáneamente.

🔧 Alternativas sin Hardware Físico

Simuladores gratuitos: Wokwi.com (recomendado), Tinkercad Circuits. Permiten probar el código completo sin comprar ESP32 ni componentes.

Versión Básica (con delay)

// Pin del LED integrado en ESP32
const int LED_PIN = 2;

void setup() {
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_PIN, HIGH);
    delay(1000);  // Esperar 1 segundo
    digitalWrite(LED_PIN, LOW);
    delay(1000);  // Esperar 1 segundo
}

⚠️ Problema con delay()

El delay() bloquea TODO el programa. Durante ese segundo, el ESP32 no puede hacer nada más.

Versión Profesional (sin delay)

const int LED_PIN = 2;

unsigned long tiempoAnterior = 0;
const long intervalo = 1000;  // 1 segundo
int estadoLED = LOW;

void setup() {
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    unsigned long tiempoActual = millis();
    
    if (tiempoActual - tiempoAnterior >= intervalo) {
        tiempoAnterior = tiempoActual;
        estadoLED = !estadoLED;  // Toggle
        digitalWrite(LED_PIN, estadoLED);
    }
    
    // ¡Aquí puedes hacer otras tareas!
    // Leer sensores, checar botones, etc.
}

✅ Ventaja de millis()

No bloquea el programa. Permite multitarea.

const int LED_PIN = 2;
const int BOTON_PIN = 15;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BOTON_PIN, INPUT_PULLUP);
  Serial.begin(115200);
}

void loop() {
  if (digitalRead(BOTON_PIN) == LOW) {
    digitalWrite(LED_PIN, HIGH);  // Presionado
  } else {
    digitalWrite(LED_PIN, LOW);   // Suelto
  }
  delay(100);
}

☀️ Proyecto 3: Sensor de Luz (LDR)

¿Qué es el LDR?

LDR (Light Dependent Resistor) = Fotoresistencia

CondiciónResistencia
OscuroAlta (MΩ)
IluminadoBaja (Ω)

Conexión (Divisor de Voltaje)

3.3V → LDR → GPIO34 → Resistencia 10KΩ → GND

Más luz = Mayor valor ADC | Menos luz = Menor valor ADC

Código

const int LDR_PIN = 34;
const int LED_PIN = 2;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int valorLuz = analogRead(LDR_PIN);
  int porcentaje = map(valorLuz, 0, 4095, 0, 100);

  Serial.print("Luz: ");
  Serial.print(porcentaje);
  Serial.println("%");

  // LED se enciende si está oscuro
  digitalWrite(LED_PIN, valorLuz < 1000);
  delay(500);
}

Código: LED Dimmer

const int LED_PIN = 2;
const int PWM_CHANNEL = 0;      // Canal 0-15
const int PWM_FREQ = 5000;      // 5 KHz
const int PWM_RESOLUTION = 8;   // 8 bits: 0-255

void setup() {
    ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RESOLUTION);
    ledcAttachPin(LED_PIN, PWM_CHANNEL);
}

void loop() {
    // Fade in (aumentar brillo)
    for (int brillo = 0; brillo <= 255; brillo++) {
        ledcWrite(PWM_CHANNEL, brillo);
        delay(10);
    }
    
    // Fade out (disminuir brillo)
    for (int brillo = 255; brillo >= 0; brillo--) {
        ledcWrite(PWM_CHANNEL, brillo);
        delay(10);
    }
}

ledcAttachPin(pin, ch)Asocia pin a canal
ledcWrite(ch, duty)Escribe valor (0-255)
ledcDetachPin(pin)Libera pin

🌡️ Proyecto 5: Sensor DHT11 (Temperatura y Humedad)

🎯 Aprendizaje Clave

El sensor DHT11 demuestra cómo leer datos de sensores digitales con librerías. La validación de datos (isnan()) es crítica para detectar fallos de comunicación.

Instalación de Librería

Arduino IDE → Sketch → Include Library → Manage Libraries → Buscar "DHT sensor library" (Adafruit)

Conexión

ESP32DHT11
3.3VVCC
GNDGND
GPIO4 ── 10KΩ ──►DATA

Resistencia 10KΩ entre DATA y VCC (pull-up)

Especificaciones DHT11

ParámetroValor
Rango temperatura0°C a 50°C (±2°C)
Rango humedad20% a 80% RH (±5%)
Tiempo entre lecturasMínimo 2 segundos

Código

#include "DHT.h"

const int DHT_PIN = 4;
DHT dht(DHT_PIN, DHT11);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (isnan(h) || isnan(t)) {
    Serial.println("Error DHT11!");
    delay(2000);
    return;
  }

  Serial.print("Temp: ");
  Serial.print(t);
  Serial.print("°C  Hum: ");
  Serial.print(h);
  Serial.println("%");
  delay(2000);
}

Descripción

Crear un sistema que:

  1. Mida temperatura con DHT11
  2. Indique estado con LEDs:
    • 🔴 Rojo: > 30°C (Calor)
    • 🟢 Verde: 20-30°C (Normal)
    • 🔵 Azul: < 20°C (Frío)
  3. Muestre valores en Monitor Serial

Resistencia pull-up de 10KΩ entre DATA y VCC del DHT11

Solución de Referencia

#include "DHT.h"

const int DHT_PIN = 4;
const int LED_ROJO = 18;
const int LED_VERDE = 19;
const int LED_AZUL = 21;

DHT dht(DHT_PIN, DHT11);

void setup() {
  Serial.begin(115200);
  pinMode(LED_ROJO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_AZUL, OUTPUT);
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();

  if (isnan(temp)) {
    Serial.println("Error de sensor");
    delay(2000);
    return;
  }

  // Apagar todos
  digitalWrite(LED_ROJO, LOW);
  digitalWrite(LED_VERDE, LOW);
  digitalWrite(LED_AZUL, LOW);

  // Activar LED correspondiente
  if (temp > 30.0) {
    digitalWrite(LED_ROJO, HIGH);
    Serial.println("Calor extremo");
  }
  else if (temp >= 20.0) {
    digitalWrite(LED_VERDE, HIGH);
    Serial.println("Temperatura normal");
  }
  else {
    digitalWrite(LED_AZUL, HIGH);
    Serial.println("Frío");
  }

  delay(2000);
}

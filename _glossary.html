📚 Glosario de Términos IoT

Curso: IF0112 Complementaria II (IoT) - UNAULA
Semestre: 6° Semestre - Ingeniería Informática
Última actualización: 2026-02-01

Este glosario define los términos técnicos, siglas y abreviaturas utilizadas en las 16 clases del curso de Internet of Things (IoT).

#
4G LTE-M / 5G IoT Fourth Generation Long-Term Evolution Machine-Type / Fifth Generation IoT
Tecnologías de red móvil de cuarta y quinta generación optimizadas para IoT con bajas potencias y latencias mejoradas.
Comunicaciones
A
ADC Analog-to-Digital Converter
Conversor Analógico-Digital - Convierte señales analógicas del mundo real (temperatura, voltaje) a valores digitales que los microcontroladores pueden procesar.
Hardware
API Application Programming Interface
Interfaz de Programación de Aplicaciones - Conjunto de reglas y protocolos que permite que diferentes aplicaciones de software se comuniquen entre sí.
Software
Arduino
Plataforma de electrónica abierta basada en hardware y software fáciles de usar, popular para prototipado IoT.
Hardware
B
BLE Bluetooth Low Energy
Versión de Bluetooth optimizada para consumo de energía muy bajo, ideal para dispositivos IoT y wearables. Alcance típico de 10-50 metros.
Comunicaciones
C
Cloud Cloud Computing
Computación en la Nube - Entrega de servicios de computación (servidores, almacenamiento, bases de datos) a través de Internet.
Arquitectura
CPU Central Processing Unit
Unidad Central de Procesamiento - Componente de computadora que ejecuta instrucciones de programas de computadora.
Hardware
D
DAC Digital-to-Analog Converter
Conversor Digital-Analógico - Convierte valores digitales a señales analógicas para controlar dispositivos del mundo real.
Hardware
DHCP Dynamic Host Configuration Protocol
Protocolo de Configuración Dinámica de Host - Protocolo de red que asigna automáticamente direcciones IP y otros parámetros de configuración a dispositivos.
Redes
DIKW Data-Information-Knowledge-Wisdom
Jerarquía que representa la transformación progresiva de datos brutos en sabiduría actionable. Datos → Información → Conocimiento → Sabiduría.
Datos
DNS Domain Name System
Sistema de Nombres de Dominio - Sistema jerárquico y distribuido que traduce nombres de dominio legibles por humanos a direcciones IP.
Redes
E
EEPROM Electrically Erasable Programmable Read-Only Memory
Memoria Programable y Borrable Eléctricamente - Memoria no volátil que puede ser borrada y reescrita eléctricamente, usada para guardar configuraciones.
Hardware
Edge Edge Computing
Computación en el Borde - Procesamiento de datos cerca de la fuente de datos (en el "borde" de la red) en lugar de en la nube centralizada.
Arquitectura
ESP32
Microcontrolador Espressif de 32 bits con WiFi y Bluetooth integrados, muy popular para proyectos IoT por su bajo costo y comunidad activa.
Hardware
ESP8266
Microcontrolador Espressif con WiFi integrado - Predecesor del ESP32, chip de bajo costo con WiFi integrado que popularizó IoT para makers.
Hardware
F
Firmware
Software de bajo nivel que controla el hardware de un dispositivo directamente.
Software
Flash Flash Memory
Memoria Flash - Tipo de memoria no volátil que puede ser borrada y reprogramada en bloques, usada para almacenamiento de código y datos.
Hardware
Fog Fog Computing
Computación en la Niebla - Arquitectura descentralizada que procesa datos entre el edge y la nube, reduciendo latencia.
Arquitectura
G
GPIO General-Purpose Input/Output
Entrada/Salida de Propósito General - Pines de un microcontrolador configurables como entrada o salida para conectar sensores y actuadores.
Hardware
Grafana
Plataforma de visualización de código abierto para crear dashboards interactivos de datos de series temporales.
Software
GPRS General Packet Radio Service
Servicio General de Paquetes por Radio - Servicio de datos móviles de conmutación por paquetes en redes GSM.
Comunicaciones
GPS Global Positioning System
Sistema de Posicionamiento Global - Sistema de navegación por satélite que proporciona ubicación y tiempo en cualquier condición climática.
Sensores
GSM Global System for Mobile Communications
Sistema Global para Comunicaciones Móviles - Estándar desarrollado por ETSI para redes de telefonía móvil digital.
Comunicaciones
H
HTTP Hypertext Transfer Protocol
Protocolo de Transferencia de Hipertexto - Protocolo de comunicación request-response para transferencia de datos en la World Wide Web.
Protocolos
HTTPS HTTP Secure
HTTP Seguro - Versión cifrada de HTTP que utiliza TLS/SSL para comunicaciones seguras.
Protocolos
HiveMQ
Broker MQTT empresarial escalable basado en Java para comunicaciones IoT.
Software
I
IC Integrated Circuit
Circuito Integrado - Conjunto de circuitos electrónicos miniaturizados en un chip de material semiconductor.
Hardware
IoE Internet of Everything
Internet de Todo - Concepto de Cisco que expande IoT para incluir personas, procesos y datos además de cosas.
Conceptos
IoT Internet of Things
Internet de las Cosas - Red de objetos físicos ("cosas") incrustados con sensores, software y conectividad que les permite recolectar e intercambiar datos sin intervención humana directa.
Conceptos
IP Internet Protocol
Protocolo de Internet - Protocolo de comunicaciones que enruta paquetes de datos a través de fronteras de red hacia su destino.
Redes
I2C Inter-Integrated Circuit
Inter-Circuito Integrado - Protocolo de comunicación serial sincrónica para conectar circuitos integrados de baja velocidad.
Comunicaciones
J
JSON JavaScript Object Notation
Notación de Objetos de JavaScript - Formato ligero de intercambio de datos, fácil de leer y escribir para humanos.
Datos
L
LAN Local Area Network
Red de Área Local - Red de computadoras que conecta dispositivos en un área geográfica limitada como una casa o edificio.
Redes
LCD Liquid Crystal Display
Pantalla de Cristal Líquido - Pantalla plana que usa cristales líquidos modulados para mostrar imágenes y texto.
Hardware
LED Light-Emitting Diode
Diodo Emisor de Luz - Dispositivo semiconductor que emite luz cuando corriente eléctrica fluye a través de él.
Hardware
LiDAR Light Detection and Ranging
Detección y Medición por Luz - Tecnología de detección remota que usa luz láser para medir distancias y crear mapas 3D.
Sensores
LLM Large Language Model
Modelo de Lenguaje Grande - Modelo de IA entrenado con grandes cantidades de texto para comprender y generar lenguaje natural.
IA
LoRa Long Range
Largo Alcance - Tecnología de comunicación inalámbrica de bajo consumo y largo alcance (hasta 15 km) para IoT.
Comunicaciones
LoRaWAN Long Range Wide Area Network
Red de Área Amplia de Largo Alcance - Protocolo de comunicación de bajo consumo para redes inalámbricas de largo alcance basado en LoRa.
Comunicaciones
LTE Long-Term Evolution
Evolución a Largo Plazo - Estándar de comunicación móvil inalámbrica de alta velocidad para datos y telefonía móvil.
Comunicaciones
M
MAC Media Access Control
Control de Acceso al Medio - Dirección física única asignada a la tarjeta de red de un dispositivo para identificación en la red.
Redes
MAN Metropolitan Area Network
Red de Área Metropolitana - Red que conecta un área urbana mayor que LAN pero menor que WAN.
Redes
M2M Machine-to-Machine
Máquina a Máquina - Comunicación directa entre dispositivos sin intervención humana, base fundamental de IoT para automatización.
Patrones IoT
M2P Machine-to-Person
Máquina a Persona - Comunicación desde un dispositivo hacia una persona, típicamente mediante notificaciones o alertas.
Patrones IoT
Mosquitto
Eclipse Mosquitto - Broker MQTT open source ligero que implementa protocolo MQTT.
Software
MQTT Message Queuing Telemetry Transport
Protocolo de Cola de Mensajes para Telemetría - Protocolo de mensajería ligero publish/subscribe diseñado para dispositivos IoT con recursos limitados.
Protocolos
N
NFC Near Field Communication
Comunicación de Campo Cercano - Tecnología de comunicación inalámbrica de corto alcance (~4cm) usada en pagos y transferencia de datos.
Comunicaciones
NB-IoT Narrowband Internet of Things
IoT de Banda Estrecha - Estándar de comunicación celular de bajo ancho de banda y bajo consumo diseñado específicamente para IoT.
Comunicaciones
O
OTA Over-The-Air
Por el Aire - Método de distribución de actualizaciones de software a dispositivos de forma inalámbrica sin conexión física.
Software
OLED Organic Light-Emitting Diode
Diodo Emisor de Luz Orgánico - Tipo de pantalla donde cada píxel es un LED orgánico que emite su propia luz.
Hardware
P
P2P Person-to-Person
Persona a Persona - Comunicación entre personas mediada por dispositivos IoT, como en sistemas de teleasistencia.
Patrones IoT
P-P-D-C Plan-Do-Check-Act
Planificar-Hacer-Verificar-Actuar - Ciclo de mejora continua (también conocido como PDCA) utilizado para gestión de proyectos y procesos IoT.
Metodología
PAN Personal Area Network
Red de Área Personal - Red de computadoras utilizada para comunicación entre dispositivos cercanos a una persona (alcance de ~10 metros).
Redes
PlatformIO
Herramienta profesional de desarrollo embebido multiplataforma con soporte para múltiples plataformas.
Software
PWM Pulse-Width Modulation
Modulación por Ancho de Pulso - Técnica para controlar el voltaje analógico promedio usando señales digitales de pulsos rápidos.
Hardware
R
RAM Random Access Memory
Memoria de Acceso Aleatorio - Memoria volátil que almacena datos temporalmente mientras el procesador los necesita.
Hardware
REST Representational State Transfer
Transferencia de Estado Representacional - Estilo arquitectónico para sistemas distribuidos que utiliza operaciones HTTP estándar.
Arquitectura
RFID Radio-Frequency Identification
Identificación por Radiofrecuencia - Tecnología de identificación inalámbrica que usa etiquetas o tarjetas con chips para transmitir datos.
Sensores
ROI Return on Investment
Retorno sobre Inversión - Métrica financiera que mide la rentabilidad de una inversión comparando ganancia con costo inicial.
Negocios
ROM Read-Only Memory
Memoria de Solo Lectura - Memoria no volátil que almacena datos permanentes que no pueden ser modificados después de la fabricación.
Hardware
Raspberry Pi
Computadora de placa reducida (single-board computer) de bajo costo, usada para proyectos IoT y educación.
Hardware
S
SDK Software Development Kit
Kit de Desarrollo de Software - Conjunto de herramientas de desarrollo para crear aplicaciones para una plataforma específica.
Software
Sigfox
Tecnología de red de área amplia de bajo consumo para comunicaciones pequeñas y esporádicas entre dispositivos IoT.
Comunicaciones
SPI Serial Peripheral Interface
Interfaz Periférica Serial - Protocolo de comunicación serial de alta velocidad para conectar microcontroladores y periféricos.
Comunicaciones
SSID Service Set Identifier
Identificador de Conjunto de Servicio - Nombre que identifica una red WiFi visible para los usuarios.
Redes
T
TCP Transmission Control Protocol
Protocolo de Control de Transmisión - Protocolo de transporte orientado a conexión que garantiza entrega ordenada y confiable de datos.
Redes
ThingSpeak
Plataforma IoT de código abierto para almacenar y recuperar datos de dispositivos mediante HTTP.
Software
TinyML Tiny Machine Learning
Aprendizaje Automático Tiny - Campo del ML que permite ejecutar modelos de IA en microcontroladores con recursos muy limitados.
IA
U
UART Universal Asynchronous Receiver-Transmitter
Receptor-Transmisor Asincrónico Universal - Circuito de comunicación serial asíncrona para transmitir y recibir datos entre dispositivos.
Comunicaciones
UDP User Datagram Protocol
Protocolo de Datagramas de Usuario - Protocolo de transporte sin conexión, rápido pero sin garantías de entrega.
Redes
URL Uniform Resource Locator
Localizador Uniforme de Recursos - Dirección que especifica la ubicación de un recurso en Internet.
Redes
URI Uniform Resource Identifier
Identificador Uniforme de Recursos - Cadena de caracteres que identifica un recurso particular en una red.
Redes
USB Universal Serial Bus
Bus Serial Universal - Estándar industrial para cables, conectores y protocolos de comunicación para conexión de periféricos.
Hardware
V
VPN Virtual Private Network
Red Privada Virtual - Tecnología que crea una conexión segura y cifrada sobre una red pública menos segura como Internet.
Seguridad
W
WAN Wide Area Network
Red de Área Amplia - Red de telecomunicaciones que se extiende sobre un área geográfica grande.
Redes
WiFi Wireless Fidelity
Fidelidad Inalámbrica - Tecnología de redes inalámbricas basada en estándares IEEE 802.11 para conectividad de área local.
Comunicaciones
Wokwi
Simulador online de electronics que permite probar código Arduino y ESP32 sin hardware físico.
Software
Z
Zigbee
Especificación de redes de área personal de alto nivel basada en IEEE 802.15.4 para bajo consumo.
Comunicaciones
Z-Wave
Protocolo de comunicación inalámbrico de bajo consumo usado principalmente en domótica.
Comunicaciones

🔌 Guía de Emulador Wokwi

ESP32 Simulator - Practica sin hardware físico

⚠️ IMPORTANTE: Wokwi es excelente para aprender y practicar, pero para el proyecto final necesitarás hardware físico para la demostración completa.

¿Qué es Wokwi?

Wokwi es un simulador online gratuito que permite diseñar, codificar y simular proyectos de electrónica y IoT directamente en tu navegador. Soporta:

  • ✅ ESP32 (con WiFi simulado)
  • ✅ Arduino, Raspberry Pi Pico, STM32
  • ✅ Sensores: DHT22, LDR, ultrasonido, etc.
  • ✅ Actuadores: LEDs, displays, motores
  • ✅ Comunicación: MQTT, JSON (simulados)

URL: https://wokwi.com/esp32

Cómo Usar Wokwi para el Curso

1
Ir a Wokwi ESP32

Abre https://wokwi.com/esp32 y haz clic en "New project"

2
Agregar Componentes

En el panel izquierdo, busca y arrastra los componentes al área de trabajo:

  • ESP32 (el microcontrolador principal)
  • DHT22 (sensor temperatura/humedad)
  • LED + Resistencia (para indicación)
  • Push Button (opcional, para interacción)
  • Resistencias según se necesiten
3
Conectar los Componentes

Arrastra los cables desde los pines del ESP32 a los pines de los componentes. Wokwi te guiará con líneas verdes cuando la conexión es válida.

4
Escribir el Código

En el editor de código a la derecha, escribe o pega tu código ESP32. Wokwi compila automáticamente mientras escribes.

🚀 Abrir Proyecto en Blanco
5
Ejecutar y Depurar

Presiona "Run" para iniciar la simulación. Podrás ver:

  • ✅ El LED parpadeando
  • ✅ Salida serial en la consola inferior
  • ✅ Los valores de los sensores cambiando en tiempo real

Proyecto Ejemplo: LED + Botón

Copia y pega este código en un proyecto nuevo de Wokwi:

// Control de LED con Botón #define LED_PIN 2 #define BUTTON_PIN 4 void setup() { pinMode(LED_PIN, OUTPUT); pinMode(BUTTON_PIN, INPUT); } void loop() { if (digitalRead(BUTTON_PIN) == HIGH) { digitalWrite(LED_PIN, HIGH); } else { digitalWrite(LED_PIN, LOW); } delay(100); }
🚀 Probar en Wokwi

Proyecto para el Curso: Monitor Ambiental

Para simular el proyecto del curso (DHT22 + LDR + WiFi):

  1. Agregar ESP32 al área de trabajo
  2. Agregar DHT22 (sensor temperatura/humedad)
  3. Agregar LDR (sensor de luz)
  4. Conectar según diagrama (ver clase-02-materiales.html)
  5. Usar código ThingSpeak del curso

Nota: El WiFi en Wokwi es simulado - NO se conectará a internet real, pero puedes probar el código de conexión.

Compartir tu Proyecto

1. Guardar: Wokwi guarda automáticamente tu proyecto

2. Compartir: Copia la URL del navegador y envíala a compañeros/docente

3. Exportar: Puedes descargar el código como archivo .ino

Limitaciones Importantes

  • ❌ WiFi NO es real: Wokwi simula la conexión pero no se conecta a redes reales
  • ❌ ThingSpeak NO funcionará: El código puede ser correcto pero no se enviarán datos reales
  • ❌ Sensores limitados: No todos los sensores reales están disponibles
  • ❌ Timing es diferente: Los delays no son exactos como en hardware real

Recomendación: Usa Wokwi para aprender y practicar código. Luego prueba en hardware real para verificar funcionamiento completo.

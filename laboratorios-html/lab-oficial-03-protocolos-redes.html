📚 Parte 1: Teoría de Protocolos (20 min)

HTTP vs MQTT para IoT

Característica HTTP MQTT
Modelo Request/Response (petición/respuesta) Publish/Subscribe (publicar/suscribir)
Overhead Alto (headers extensos) Bajo (headers mínimos)
Batería Consume más (conexiones cortas) Consume menos (conexión persistente)
Casos de uso APIs REST, envío periódico de datos Comandos en tiempo real, alertas
Ejemplo IoT Enviar temperatura cada 5 minutos Encender luz cuando se detecta movimiento
💡 Concepto Clave para E3: MQTT usa un broker (intermediario) que recibe todos los mensajes y los distribuye a los dispositivos suscritos. Esto permite comunicación muchos-a-muchos eficiente.

Conceptos MQTT Esenciales

  • Topic (Tema): Canal donde se publican mensajes (ej: casa/sala/temperatura)
  • Publish (Publicar): Enviar un mensaje a un topic
  • Subscribe (Suscribir): Recibir mensajes de un topic
  • Broker: Servidor que gestiona los mensajes (ej: Mosquitto, HiveMQ, broker público)
  • QoS (Calidad de Servicio): Nivel de garantía de entrega (0, 1 o 2)

Paso 3: Código Arduino

/*
 * LAB 3: Envío de datos a ThingSpeak (HTTP GET)
 * Preparación para E3 - Protocolos IoT
 */

#include <WiFi.h>
#include <HTTPClient.h>
#include "DHT.h"

// ⚠️ CONFIGURACIÓN: Reemplaza con tus datos
const char* ssid = "TU_WIFI_SSID";
const char* password = "TU_WIFI_PASSWORD";
const String apiKey = "TU_WRITE_API_KEY";  // De ThingSpeak
const String channelID = "TU_CHANNEL_ID";

// Configuración DHT22
#define DHTPIN 4
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

// Variables para timing no bloqueante
unsigned long lastTime = 0;
const unsigned long timerDelay = 20000;  // 20 segundos entre envíos

void setup() {
  Serial.begin(115200);
  dht.begin();
  
  // Conectar a WiFi
  WiFi.begin(ssid, password);
  Serial.print("Conectando a WiFi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\n✓ WiFi Conectado");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  // Enviar datos cada 20 segundos (sin bloquear)
  if (millis() - lastTime > timerDelay) {
    
    // Leer sensores
    float temperatura = dht.readTemperature();
    float humedad = dht.readHumidity();
    
    // Validar lecturas
    if (isnan(temperatura) || isnan(humedad)) {
      Serial.println("⚠ Error leyendo DHT22");
      return;
    }
    
    Serial.printf("🌡 Temperatura: %.1f°C | 💧 Humedad: %.1f%%\n", 
                  temperatura, humedad);
    
    // Enviar a ThingSpeak (HTTP GET)
    if (WiFi.status() == WL_CONNECTED) {
      HTTPClient http;
      
      // Construir URL
      String url = "http://api.thingspeak.com/update?api_key=" + apiKey;
      url += "&field1=" + String(temperatura);
      url += "&field2=" + String(humedad);
      
      Serial.println("📤 Enviando a ThingSpeak...");
      http.begin(url);
      int httpCode = http.GET();
      
      if (httpCode == 200) {
        String payload = http.getString();
        Serial.println("✓ Datos enviados correctamente. Entry: " + payload);
      } else {
        Serial.printf("✗ Error HTTP: %d\n", httpCode);
      }
      http.end();
    }
    
    lastTime = millis();
  }
}

🔧 Troubleshooting Común

Síntoma Causa probable Solución
No conecta a WiFi Credenciales incorrectas Verificar SSID y password exactos (distinguen mayúsculas)
Error HTTP -401 API Key incorrecta Copiar Write API Key exacta de ThingSpeak
Error HTTP 0 Sin conexión internet Verificar que WiFi tenga acceso a internet
DHT22 devuelve NaN Conexión incorrecta o librería Verificar cableado e instalar librería DHT (Adafruit)
Datos no aparecen en ThingSpeak Límite de rate (15 seg mínimo) ThingSpeak acepta datos máximo cada 15 segundos
